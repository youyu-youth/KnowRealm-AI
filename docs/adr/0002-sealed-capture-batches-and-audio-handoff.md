# 封口捕获批次与录音交棒边界

一个 Record 的多来源输入必须作为有序捕获批次一次提交并封口，正式注册前整批预校验，内容处理开始后不得追加或重排；批次内全部音频总时长不得超过 5 小时。Capture Batch 是一次性创建命令，不新增持久化批次实体；长期对象仍是 Record、顺序来源文件及其处理 Job，混合来源的 Record 标记为 `MULTI_SOURCE`。录音功能只负责分片暂存、恢复与 finalize；音频管线负责合并、转码、正式来源注册、临时文件清理和 ASR。只有全部来源成功后才原子发布完整 Transcript；任一来源失败都不发布部分正文。该边界避免两个功能共同拥有音频产物生命周期，并让聚合只有一个完成条件。
