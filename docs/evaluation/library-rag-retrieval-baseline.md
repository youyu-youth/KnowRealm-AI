## 1. 用途与口径

- 目的：在 `LibraryRetrievalService` 实施前冻结真实查询黄金集与四指标阈值，作为工单 07 发布门禁判据与 sqlite-vec 是否进入本波次的唯一依据（ADR-0024）。
- 被测基线 = V1 冻结检索链「Segment FTS（BM25）+ CONFIRMED Concept 扩展并跑」，即 `LibraryRetrievalService` 将收编的管线；不含 B2 迁移期 LIKE 兜底（服务契约按 spec 不含兜底路径）。数值常量直接复用 agent 工具冻结值（命中上限 8 / 概念上限 4）。
- 口径声明：黄金集为**编写真实样料 + 合成构造混合**（内容取材于真实讲义/论文/笔记文体，逐条人工标注期望命中），不依赖用户真机数据。真实用户语料评测并入工单 07 门禁复跑与用户真机验收。合成样料达标证明链路正确性与阈值可复跑，不证明真实语料召回率上限。
- 复跑命令：`cd backend && uv run pytest tests/test_library_retrieval_eval.py --basetemp=.pytest-tmp -s`（测后删除临时目录）。

## 4. 实测基线（2026-09-19，首测即冻结）

| 指标 | 实测 | 冻结阈值（07 门禁） | 说明 |
| --- | --- | --- | --- |
| Recall@8（宏平均） | **0.941**（16/17 查询全命中；分片口径 25/26） | **≥ 0.90** | 唯一未达 1.0 的是 en-inflection 样本（设计内） |
| MRR | **0.941**（16 条 rank=1） | **≥ 0.90** | 同上 |
| 无答案准确率 | **1.000**（3/3 零命中） | **= 1.0**（零容忍） | 假阳性即门禁失败 |
| 引用正确率 | **1.000**（25/25 实测命中逐字回表 + 归属标题 + 时间轴/页码定位正确） | **= 1.0**（零容忍） | 逐字 quote 与语料一致、音频带时间区间、文档带页码 |
| 作用域泄漏 | **0** | **= 0**（零容忍） | 全部 20 条查询无范围外命中 |

阈值语义：Recall/MRR 阈值 0.90 = 容忍至多 1 条查询失败（17 条正例）；任一新增失败即跌破阈值变红。无答案准确率、引用正确率、作用域泄漏为零容忍硬门禁。

## 5. sqlite-vec 触发判据（冻结）

- **词汇错配失败的定义**：正例查询未命中任一期望分片，且失败模式为查询与全部期望分片无共同 FTS 词元、Concept 扩展亦未桥接（词面完全不重合；词形屈折 reduce≠reduces、parallel≠parallelization 属此类）。
- **启用判据（两条件同时满足才开 PoC 票）**：
  1. 黄金集或真实语料门禁中，词汇错配失败 ≥ 3 条查询（17 条正例中占比 ≈18%）或成为**主要**失败模式；
  2. sqlite-vec 混合召回 PoC 在同一黄金集上 Recall@8 净增益 ≥ 10 个百分点，且无答案准确率、引用正确率、作用域泄漏三项不退化。
- **当前判定**：1/17（5.9%）失败、全部归因英文屈折 → 未达条件 1 → **sqlite-vec / semantic_embeddings 不进入本波次**，与 CB-01 先例结论一致。重开条件：工单 07 真实语料门禁或后续迭代中词汇错配成为主要失败模式（届时新开 LIB-VEC 票，`semantic_embeddings` 按数据模型 v3.0 直接使用 `library_item_id` 列名，无需再改名）。

## 6. 英文内容对 jieba 分词链路的召回结论（冻结）

- **实测链路行为**：`jieba.cut_for_search` 对英文按空白整词透传（不切碎、不翻译）；索引侧与查询侧共用同一 tokenizer；大小写由 FTS5 unicode61 归一；连字符词（self-attention、multi-head）在两侧一致拆分。
- **结论：无需在实施票补英文分词处理**。英文精确词形召回 4/4 查询全过（含连字符与多词 AND）；混合中英文档（MVCC、Attention 论文体）召回正常。
- **已知边界**：无词干归一（stemming）——英文屈折变化（复数、动词变位：reduces≠reduce、mechanisms≠mechanism、parallelization≠parallel）不匹配。该边界**不通过改分词器解决**（词干器增加链路复杂度且对中文主场景零收益），作为词汇错配子类纳入 §5 触发监测；若真实语料英文占比高且屈折失败成为主要模式，优先评估轻量英文词干归一或直接进入 sqlite-vec 评估。
