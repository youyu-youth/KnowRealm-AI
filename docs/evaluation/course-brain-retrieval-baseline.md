## 1. 用途与口径

- 目的：在引入向量检索前，验证「Concept 命中 → 检索词扩展（原查询 + canonical_name 并跑）→ Segment 原文引用」的召回是否够用，形成 sqlite-vec 是否进入本 Epic 的门禁结论。
- 口径（重要）：本评测使用**人工构造的合成课程语料**，不依赖用户真机数据。**合成样例达标 ≠ 真实语料达标**；真实语料评测并入 CB-12 用户真机验收清单（执行主体为用户，结论另记）。
- 复跑命令：`cd backend && uv run pytest tests/test_course_brain_retrieval_eval.py --basetemp=.pytest-tmp`（测后删除临时目录）。

## 4. 失败归因

无失败。四维全部通过，不存在「主要失败来自词汇不重合」的证据，不触发 CB-VEC 升级条件。

## 5. 结论

- **sqlite-vec / semantic_embeddings 不进入 F4 Course Brain V1**（默认「延后」结论成立，ADR-0022 维持）。
- 升级路径按优先级保留：① `concepts.terms` 同义词扩展列（词汇不重合失败时优先修此处）；② query-time LLM 查询扩展；③ 引入 sqlite-vec 向量检索（届时新开 CB-VEC 票）。
- 重开触发条件：CB-12 真实语料评测或后续迭代中出现「词汇不重合导致召回失败」为主要失败模式。

## 6. 口径声明（防误读）

- 本结论只对合成样例负责：证明的是链路正确性（概念命中 → 扩展 → 去重 → 逐字回表），**不证明真实语料召回率**。
- 合成语料规模小（2 概念 / 5 分片 / 4 查询），未覆盖：口语化转写噪声、ASR 同音错字、超长文档分片、跨课程同名概念干扰、纯符号/停用词查询等；这些留给 CB-12 真实语料评测与后续回归。
- ASR 错字等词面误差是词面检索的已知边界；本评测按 spec Q8 用「同义词 / 简称」代表词面不重合场景。
