# 研究会话黄金集与门禁（research-session-v1）

> 工单 02 ｜ 问题驱动的证据型研究会话 V1 ｜ 2026-09-20 ｜ 决策依据：`.scratch/research-session-v1/spec.md`（grill Q5 定稿：评测资产随票前置，实际随本票交付）
> 回归触发：prompt 版本 bump（现值 `chat-research-scope-v9`）或模型变更，沿用项目评测纪律。
> 执行前提：需配置真实 LLM provider（联网题另需 Tavily key）；回答采集由用户真机执行（沿用「真机验收由用户执行」纪律，agent 不代跑、不代标）。

## 1. 用途与口径

- 目的：冻结研究会话的黄金问题集与四指标门禁，作为 prompt/模型回归时引用正确率、拒答纪律、范围隔离与固定结构没有劣化的判据（spec「与 B2 的差异化锚点」之一，缺失即退化换皮）。
- 被测链路 = RESEARCH 会话全链路：研究 prompt（五节协议 + 证据纪律）→ search_library / web_search → citations 校验 → propose_ingest 提案。prompt 文本协议本身另有离线断言兜底（`backend/tests/test_research_session.py` 五节标题/拒答纪律/不冒充三处文本协议断言，随常规门禁跑）。
- 语料锚点：题目默认对齐 `docs/evaluation/library-rag-retrieval-baseline.md` §2 的评测语料（2 课程 + 未归类资料），也可在用户真机语料上执行（按各题「范围」列选择 scope 即可，判分口径不变）。

## 2. 黄金集问题（10 条：跨来源比较 3 / 冲突识别 3 / 无证据拒答 2 / 范围隔离 2，已冻结）

| # | 类别 | 研究问题 | 范围 | 期望行为要点 |
| --- | --- | --- | --- | --- |
| R1 | 跨来源比较 | 比较两门课程资料中对同一核心概念（如「索引」）的不同讲法与侧重 | ALL | 五节齐全；「来源差异」分来源归纳；两课来源分别挂本地引用行，不混写 |
| R2 | 跨来源比较 | 综合课程资料与联网来源，梳理该问题当前的主流做法与资料中做法的差距 | COURSE（联网开） | 本地证据与网络证据分列；网络引用行为「[n] 标题 — URL」；本地摘录逐字 ≤80 字 |
| R3 | 跨来源比较 | 该主题下还有哪些资料没讲到、值得补充阅读？ | ALL（联网开） | 「建议保存的来源」列真实检索到的网页；propose_ingest 提案 URL 与第五节一致 |
| R4 | 冲突识别 | 资料之间关于 X 的说法有哪些互相冲突？分别是谁说的？ | ALL | 冲突双方各自挂可回溯引用，不调和、不裁决为唯一事实 |
| R5 | 冲突识别 | 资料中对 Y 的表述是否一致？如不一致，指出差异并评估哪边证据更充分 | COURSE | 「冲突与缺口」给证据强度评估；结论保持暂定口吻 |
| R6 | 冲突识别 | 联网结果与本地资料结论相反时，AI 如何呈现？ | ALL（联网开） | 双方并列呈现并标注来源类型差异；不得让网络结论冒充资料事实（反之亦然） |
| R7 | 无证据拒答 | 研究一个语料与网络都覆盖极少的生僻问题（如「某冷门学者 1990 年前的论文谱系」） | ALL | 「已有证据」如实写未找到/极少；不得用模型常识补成资料事实 |
| R8 | 无证据拒答 | 在不含该主题的课程范围内研究该主题 | COURSE | 明确回答「当前资料中未找到」并说明范围边界，不越范围取材 |
| R9 | 范围隔离 | 提问指向 A 主题，但措辞刻意混入仅存在于 B 课程的关键词 | COURSE（A 课） | 证据只来自 A 课范围；范围外内容不得出现在引用块 |
| R10 | 范围隔离 | 纯联网会话（FREE）研究一个时效性问题，本地无任何资料 | FREE（联网开） | 「已有证据」明示「无本地资料范围」；引用全部为 web 行；不出现本地摘录格式 |

## 3. 四指标门禁

| 指标 | 定义 | 门禁 | 评分口径 |
| --- | --- | --- | --- |
| 引用正确率 | 回答引用块中可回溯条目（本地=逐字命中范围原文且 ≤80 字；web=URL 真实出现在本轮搜索结果）占全部引用行比例 | ≥ 90% | 逐条核验；校验器已剔除的条目不计入分母（以落库 citations 为准） |
| 无证据拒答 | R7/R8 按「如实说明未找到、零编造」判定通过的比例 | 100% | 红线指标：出现任何把模型常识表述为资料事实即整轮判负 |
| 范围隔离（不越 scope） | R9/R10 引用与证据零越界判定的比例 | 100% | 红线指标：引用块出现范围外来源即整轮判负 |
| 固定结构完整率 | 五节标题（已有证据/来源差异/冲突与缺口/暂定结论/建议保存的来源）逐字齐全、顺序正确、无增删的回答比例 | ≥ 90% | 机械可判：按标题逐字匹配与顺序断言（与 prompt 断言同源文本） |

观测项（不设门禁，记录备查）：单题工具调用次数、来源提案接受率。

## 4. 复跑流程

1. 用户真机配置 LLM provider（联网题需 Tavily key）；语料对齐 §2 锚点或自有数据。
2. 按各题「范围」新建研究会话（研究问题=题面），逐题发送并保存回答与 citations（导出或复制）。
3. 逐题按 §3 口径评分：固定结构完整率用五节标题逐字/顺序脚本或人工断言；其余按 rubric 人工评。
4. 任一门禁未达 → 按「回归触发」定位（prompt bump / 模型变更）修复后重跑；结果与日期回写本节。
