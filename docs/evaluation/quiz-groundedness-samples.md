# 习题 Groundedness 黄金样本集

> 工单 20 ｜ PRD §8.4 测试策略（决策 #46）｜ 建档：2026-09-09
> 评审标准：[quiz-groundedness-checklist.md](./quiz-groundedness-checklist.md)

验证 AI 生成的习题是否忠于生成来源（已确认总结），防止无中生有。样本从真机真实使用中采集、人工标注，作为习题生成质量的回归评审基线。

**当前状态：框架已就绪，样本待采集。** 样本本体阻塞于用户真机采集（清单见下），采集后按「用户采集 → agent 整理初稿（含脱敏）→ 用户人工标注」分工补齐。

## 分工与流程

1. **用户**：从真机 UI 按「采集清单」收集原始配对材料。
2. **agent**：整理为样本初稿，按脱敏规则处理后填入本文档。
3. **用户**：对照 checklist 人工填写四维判定、总判定与证据引用（agent 不代标）。

### 采集清单（每来源一份，同来源样本间复用）

1. **完整已确认总结**：主题 + 摘要 + 全部 sections——评分锚必须是模型的完整输入，摘录会失真。
2. **转写代表性摘录**一份（参考附件）。
3. **该来源当前 ACTIVE 习题全文**：题干 / 选项 / 答案 / 解析 / 难度。
4. **模型名**（设置页可见）+ 采集日期。

## 脱敏规则

- 替换为占位符：课程名 →「课程A」、人名 →「讲师甲」、机构 / 学校名 →「大学X」等可识别信息。
- **不动学科内容**：知识点、术语、例题内容原样保留。
- agent 整理初稿时执行脱敏，用户复核后定稿；后续补样本沿用本规则。

## 元数据规范

每条样本必含：

| 字段 | 说明 |
|------|------|
| `model` | 生成该题的模型名（设置页显示名） |
| `prompt_version` | 习题生成 prompt 版本，当前 `quiz_v1` |
| `采集日期` | YYYY-MM-DD |
| `题型` | 单选 / 多选 / 判断 / 填空 / 简答 |
| `难度` | EASY（简单）/ MEDIUM（中等）/ HARD（困难） |
| `来源代号` | `SRC-A` 式，对应下方来源材料区 |

不记录 provider / latency / token。

## 来源材料区

每来源一份、按采集清单四项完整登记；总结 sections 依原文分节，分点编号 `§节-点`（如 `§2-3` = 第 2 节第 3 个分点），供样本证据引用。样本须来自 **≥2 个不同来源**（不同课堂 / 学科）。

## 样本条目

- 覆盖要求：**≥10 条；五种题型各 ≥1；来源 ≥2**。编号自 Q-01 起，采集后按下方格式由 agent 整理填入。
- **如实快照**：FAIL / PARTIAL 样本原样保留，不精选、不回改——它们是回归基线与 prompt / 模型改进前后对比的证据。
