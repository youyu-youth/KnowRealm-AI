# 习题 Groundedness 人工评审 Checklist

> 工单 20 ｜ PRD §8.4 测试策略（决策 #46）｜ 2026-09-09 定稿
> 配套样本集：[quiz-groundedness-samples.md](./quiz-groundedness-samples.md)

## 用途

人工评审一道 AI 生成的习题是否**忠于其生成来源**（忠实度 / Groundedness），用于黄金样本标注与回归评审。一次评一道题：逐维判定，再按映射规则给出总判定。

## 评分锚点

- **评分锚**：该题所在记录的**完整已确认总结**（主题 + 摘要 + 全部 sections）。习题生成时模型只能看到已确认总结与课程上下文，看不到转写全文——评审只对总结锚点负责。
- **参考附件**：转写代表性摘录。仅用于发现「总结幻觉传导到习题」，**不参与评分**。
- 转写佐证总结本身有误、而习题忠实于总结时：各维照常评定，在附注标「非习题生成缺陷，转总结域（06 黄金样本）」。

## 评审步骤

1. 通读评分锚，给总结 sections 分点编号：`§节-点`（如 `§2-3` = 第 2 节第 3 个分点）。
2. 对照题目（题干 / 选项 / 答案 / 解析）逐维判定：✅ / ❌ / N/A。
3. 填**证据引用**（必填）：支撑该题的要点编号，可多条；若题目无中生有，写「无依据」并指出幻觉内容。
4. 按下方映射规则得出总判定：PASS / PARTIAL / FAIL。
5. 如触发附注情形，写附注。

## 四个维度

| # | 维度 | 判定说明 |
|---|------|----------|
| 1 | 题干可从来源推出 | 题干的问题、情境、限定条件均能在总结要点中找到依据；允许同义改写，不允许引入总结外案例 / 数据 / 限定。 |
| 2 | 答案正确 | 答案与总结依据一致：单选 = 正确项判定无误；多选 = 正确项完整（漏选 / 多选均算 ❌）；判断 = 对 / 错判定无误；填空 = 参考答案可由总结推出；简答 = 参考答案覆盖总结相关要点且无错误表述。 |
| 3 | 选项合理 | 仅选择题评。正确项无争议（单选唯一可辩护、多选完整）；干扰项貌似合理、与题干自洽、不与正确项构成多解。 |
| 4 | 无幻觉 | 题干 / 选项 / 答案 / 解析任一处出现总结无依据的**实质内容**（具体数字、人名、机制、结论、案例）即 ❌；同义改写与常识性衔接不算。 |

- 题型不适用的维度标 **N/A**（见适配表）。
- 同一问题只计入最贴切的一维，不重复扣分：如干扰项引入总结外的具体事实断言，计入维度 4（无幻觉），不再计入维度 3。

## 逐题型适配表

| 题型 | 1 题干可推出 | 2 答案正确 | 3 选项合理 | 4 无幻觉 |
|------|:---:|:---:|:---:|:---:|
| 单选 MULTIPLE_CHOICE | ✅ | ✅ | ✅ | ✅ |
| 多选 MULTIPLE_SELECT | ✅ | ✅ | ✅ | ✅ |
| 判断 TRUE_FALSE | ✅ | ✅ | N/A（选项固定「对 / 错」） | ✅ |
| 填空 FILL_BLANK | ✅ | ✅ | N/A（无选项） | ✅ |
| 简答 SHORT_ANSWER | ✅ | ✅ | N/A（无选项） | ✅ |

## 总判定映射

| 总判定 | 规则 |
|--------|------|
| **PASS** | 四维全部 ✅ 或 N/A |
| **FAIL** | 维度 2 ❌（答案错），或维度 4 ❌（实质性幻觉） |
| **PARTIAL** | 其余：仅维度 1 或维度 3 ❌（题干超出、选项设计缺陷，但答案与依据无实质性错误） |

PARTIAL 单列是因为部分幻觉 / 部分缺陷是高频真实场景，二值判定会丢信息。

## 回归评审

- **触发条件**：习题生成 `prompt_version` 变更（当前 `quiz_v1`）或更换模型。
- 触发后用本 checklist 对样本集**全部样本重标一轮**，结果记入样本集文档末尾「回归评审记录」表。
- 不做自动对比、不做 CI。FAIL / PARTIAL 样本原样保留，作为回归基线与 prompt / 模型改进前后对比的证据。
