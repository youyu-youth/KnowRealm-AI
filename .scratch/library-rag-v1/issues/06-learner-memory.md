# 06 — Learner Memory V1：可治理的学习者长期记忆

**What to build:** 学习画像新增「AI 记忆」区域：显式学习偏好可查看、编辑、删除；观察偏好带置信度、证据数与确认时间，经用户确认才生效且永不覆盖显式偏好；对话中说「记住……」出现就地确认卡片；每轮实际注入了哪些记忆可查看；外部处理同意扩展到记忆外发并可单独关闭（关闭后记忆保留本地、本地检索不受影响）；离线时记忆管理全部可用。

**Blocked by:** 02 — Schema、存量回填与基础工作台.

**Status:** ready-for-agent

- [ ] `LearnerProfileService` 聚合偏好、掌握度、误区、近期学习证据与目标，按任务与会话范围生成限长、可重建的 Learner Context；Agent 运行前由确定性中间层注入，模型不能扩大读取范围；全局显式偏好可跨 Agent、Course 状态不越界注入、ALL 只取任务所需最小集合、受字符预算约束
- [ ] 记忆写入仅两类入口：用户在学习画像直接编辑显式偏好；结构化学习证据或用户明确「记住」生成 MEMORY 提案、确认后由 LearnerProfileService 写入 `learner_preferences`（复用 02 提案框架，本票落 MEMORY 生成方与应用器）；普通聊天零静默提取
- [ ] 对话中 MEMORY 提案就地确认卡片：确认写入、拒绝零变更；观察偏好带置信度/证据计数/时间，不覆盖用户显式偏好
- [ ] 本轮对话实际使用的记忆在 UI 可查看；Learner Context 只影响解释方式与建议，不改变 Mastery、Evidence、Quiz 判分等确定性数值
- [ ] 外部处理同意扩展：第一次范围问答前告知将发送相关来源片段与最小必要记忆并取得绑定供应商身份的同意，地址/密钥变化后重新确认；设置页「在 AI 中使用长期记忆」独立开关，关闭=不外发但本地可管理、本地检索不受影响
- [ ] 日志不记录记忆正文；全量导出/备份与升级前快照包含 learner_preferences；离线时查看、编辑、删除、本地聚合可用，依赖 LLM 的建议明确降级不产伪结果
- [ ] 硬门禁自动化用例：未经确认零写入、关闭外发后零发送、删除后零再次注入、Course 状态零越界注入；zh/en 文案同步
