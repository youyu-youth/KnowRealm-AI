KnowRealm 的第一个 Windows x64 版本，基于 main 发布。

提供课程与资料管理、文档和音频捕获、中文搜索、AI 对话与学习计划等现有能力。数据保存在本地目录，无需安装 Python、Node 或开发工具。

## 安装

下载附件 `KnowRealm_0.1.0_x64_en-US.msi` 并安装，首次启动按向导设置数据目录。AI 功能需配置自己的 OpenAI 兼容服务，语音转写需配置腾讯云 ASR。

`SHA256SUMS.txt` 用于核对下载文件是否完整。安装包尚未代码签名，Windows 可能显示未知发布者提示。

## 已验证

- 本机 Windows 安装成功，真实 Tauri/WebView2 完成首启向导并进入工作台。
- 安装后的独立后端通过课程创建、文本保存、中文搜索、TXT/PDF/DOCX 导入、FFmpeg 转码和重启持久化检查。
- 前后端代码与类型检查、Rust 启动相关测试及 Clippy 通过。

## 已知限制

- 本版数据库最高版本为 57。请使用新数据目录；不能用本版打开较新的开发版数据库，例如版本 63。不要手动降低数据库版本号。
- 部分今日页区块仍明确标记为示意。
- 双进程互斥回归存在依赖冷加载超过测试限时的问题，在未修改的 main 上也复现；本轮首次真实进程回归为 13 通过、2 超时，归档拒绝用例单独复测通过。
- 本轮未验证真实模型/腾讯 ASR、另一台干净 Windows 和各档系统缩放；不代表全部功能已完成真机验收。
