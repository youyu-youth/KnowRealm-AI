# Desktop 布局设置

两种布局：SIDEBAR（默认）保持左侧导航；TOP 在自定义标题栏下方提供独立水平导航行。菜单、窗口控制和搜索继续留在标题栏。

导航路由及禁用项共用一份定义。顶部布局按可用宽度和实际文字宽度将放不下的末尾导航项收进「更多导航」，适配语言、字号和窗口变化；近期课程以菜单访问，档案和设置始终可达。保留侧栏宽度、折叠与课程展开状态。布局切换不重新挂载 Outlet、录音控制和捕获弹窗。

持久化复用 /api/settings/preferences 与数据目录 config/settings.json，新增 layout_mode；缺失或损坏回落 SIDEBAR，默认值按既有惯例删除键，未知键保留。启动沿用 prepareAppearance 在工作区挂载前读偏好的流程；保存成功才切换，失败沿用 useSavePreference 的权威读回与错误/重试。

本期没有 Agent 自动修改外观：布局属于本地桌面呈现偏好，现有 Agent 未开放通用应用偏好写入口，避免为布局开设新的受控操作体系。偏好 API 与 config 服务复用现有能力，后续接入 Agent 时须复用同一执行路径。

用户已选择标题栏下方独立导航行。此为单会话闭环功能，一张票覆盖前后端契约、导航、设置、回归与分层验收，不改权威规范或新增依赖。
