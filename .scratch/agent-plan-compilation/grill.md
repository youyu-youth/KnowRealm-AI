## 当前确认范围

1. 收拢自动提交与计划卡确认的参数解析、引用延期、快照、步骤分类、对应关系、序号映射和可执行事实写入。
2. seam 位于计划形成可执行事实的阶段；删除两路重复编排，六元组只换具名类型不算完成。
3. 复用现有动作 adapter/schema、受控 Operation、预算、提案与 JobRunner；内部类型可优化，对外字段并集暂时保留。
4. 入口保留真实事务、授权分流、回执与生命周期接线；Worker 保留推进、等待、取消和恢复。
5. 现有 Tool/提案/Run格式、模型可见面、前端和可观察行为保真，不引入新格式、API、版本批准或重新预览。
6. 复用相关既有测试，通过实际提交/确认及真实 SQLite/Worker验证；不以内部 helper 布局或新增类型为测试目标。

## 已核实差异与验收

- 当前 AUTO_APPROVE 未确认 Run 在阈值内可自动延展/改参；旧卡可合入活跃 Run，目标终态后可另建 Run。本期保留为事实基线，不把它们当作授权期望规则，后续独立修正。
- 外部字段并集、无关字段投影及 null 解释暂时保留；本期不承诺新增动作只需修改一处。
- 现有快照、提交处取消/身份、每步授权、业务/回执原子性、独立失败记账、预算与恢复幂等不得削弱。
- 复用批量、引用等待、多资料、轮次恢复和计划卡消费测试。自动化、替身、真实 API/SQLite/Worker、真实模型和真实 Tauri分别记录；未执行真机项不代勾。
- 本轮相关后端 136 项、前端消费 29 项通过，两轴审查无发现；全量基线问题和未验证范围见实施记录，不以早期旧行为核查替代本期验收。
