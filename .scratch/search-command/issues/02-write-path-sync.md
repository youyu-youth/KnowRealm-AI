# 02 — 写路径同事务索引同步

**What to build:** 用户编辑任何可检索内容并保存后，新词立即可搜、旧词不再命中：三实体四类写路径——学习记录创建/改标题、转写落稿与编辑、知识点确认/编辑/重新生成、课程创建/改名——在同一业务事务内 upsert 索引行；业务写回滚时索引同步一并回滚。全部验收经既有 HTTP 端点完成，不新增对外 API。

**Blocked by:** 01（复用 search 模块索引 upsert 接口与索引表）。
