# 03 — 挂载对话与上下文组装

**What to build:** 新建对话时可选"挂载一条学习记录"：选择器列出存在转写的记录（含收件箱未归类；无转写的可见但置灰并说明原因）；挂载后转写全文常驻上下文，追问"后面讲的那个公式"这类细节能得到基于转写的回答。上下文按 60000 字符预算两级裁剪（超预算先裁最旧轮、转写超 3 万字降级为摘要 + 知识点 + 近 3 轮引用摘录段），每轮跟随记录最新转写版本，且不叠加角色注入。模式新建时一次选定，会话内不可换。

**Blocked by:** 02 — 自由聊天流式闭环（含中断、并发与降级）

**Status:** ready-for-agent

- [ ] 挂载选择器只列存在转写的记录（含 Inbox 未归类）；无转写的置灰并显示原因
- [ ] 挂载会话：转写全文进入上下文、无角色 SYSTEM 注入（流式 stub 捕获断言）；`course_id` 随记录填写（收件箱记录为空）
- [ ] 1 轮 = 一条成功完成的 user→assistant 往返；超预算先裁最旧对话轮（转写仍常驻）
- [ ] 转写超 3 万字时不再常驻全文，替换为已确认摘要 + 知识点全文 + 近 3 轮被引用的转写摘录段
- [ ] 上下文组装裁剪为纯函数并配最小单测（预算边界、两级阶梯、轮计数）
- [ ] 转写编辑保存后，下一轮上下文取新版本（stub 断言）
- [ ] OpenAPI → api-types 同步；后端与前端测试齐备
- [ ] 人工：挂载后追问细节，回答准确基于转写内容
