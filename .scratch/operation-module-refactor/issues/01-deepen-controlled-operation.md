# 01：收拢三入口受控执行并解除审批 ORM 耦合

**What to build:** 用户继续通过原 Agent 工具、确认卡与 Run 执行任务；确认、自动执行和 Run 的受控执行知识收拢到 Operation module，动作应用器解除审批 ORM 依赖，授权、事务、取消、回执、幂等与恢复行为保持。Undo/Retry 完成受影响契约的必要适配。

**Blocked by:** None（无前置工单；不依赖工具预算重构或草案 Job 身份问题修复）。

**Status:** done（代码与本票自动化验收完成；全量基线失败、真实模型/Tauri 未验收见实施记录）

**Parent:** [加深受控 Operation module 规格](../spec.md)

日期：2026-10-12。用户本轮调用 implement 授权实施；代码已交付，本票相关 267 用例通过；全量 1167 通过、2 个既有失败已在原始基准复现。最终验收证据见 [implementation.md](../implementation.md)。

## 交付边界

一个完整闭环覆盖全部当前注册动作和三条入口，不拆成只改应用器、只改 worker 或只补测试的分层票。内部可逐步迁移，交付时不得留下旧伪 Proposal 路径或一条入口未接通。

Operation module 保留少量明确入口 interface；入口 adapter 封装原授权、快照、记账与失败差异，共享 implementation 集中重复执行流程。现有入口持有事务，内部执行参与原事务。Proposal 审批与 Run 计划/等待/恢复生命周期保留。

## 实施顺序

1. 复核当前注册项、三入口及 Retry/Undo 调用关系，记录相关测试基线和原错误/身份协议；保护其他会话改动。
2. 在既有执行 module 内收拢共享规则及入口差异 adapter，逐项迁移动作应用器为类型化载荷与必要标识；保留类型校验与原异常映射。
3. 接通确认、自动执行、Run；迁移必要的 Retry/Undo 调用，去掉本次产生的孤立代码及伪 Proposal 兼容路径。
4. 通过原入口验证持久结果和行为差异，审查调用方编排是否确实减少，再记录验收证据与项目进度。

## 验收标准

- [x] **A01**：原 Tools、授权分流、payload/result、HTTP/SSE、确认卡与回执结构保持；非 Operation 提案继续走原流程。
- [x] **A02**：确认入口的条件抢占、编辑校验、显式批准、Proposal 状态与错误包装保持；成功同事务写业务与 Operation，失败只记 Proposal FAILED。
- [x] **A03**：自动/Run 成功的业务写入、Operation 与原投影保持原子性；自动入口 effect 同事务收口；失败回滚与独立失败记账保持入口原协议。
- [x] **A04**：原持久取消/执行身份 guard 留在提交事务，取消先提交后不新增业务副作用；已完成结果保留。单独核对独立失败事务，不静默增加或删除原 guard。
- [x] **A05**：快照比较方式、缺失快照、首次/派生基线、锁竞争期间目标变化、Run 引用注入后补快照保持；不额外重跑原本不调用的提交校验器。
- [x] **A06**：授权档 Run 与显式批准计划保持不同授权依据；降档、重规划、新增目标的规则保持。
- [x] **A07**：成功重放返回原结果/身份、预算满仍能恢复、指纹冲突拒绝；对象、回执与 Job 不重复。
- [x] **A08**：真实 Run/JobRunner 验证依赖失败、独立项继续、Job 等待/唤醒、重启接续与失败重试；已成功项不重做。
- [x] **A09**：受影响的 Undo/Retry 接通新契约，原身份、attempts、条件抢占、版本/补偿校验与并发输家投影保持。
- [x] **A10**：全部动作应用器不依赖 AgentProposal ORM，无临时 Proposal；三入口已接入共享执行 implementation。给出调用方重构前后职责对照，证明快照/应用/结果校验/成功记账不再重复编排，而非仅增加一层包装。
- [x] 草案动作显式接收必要身份，保持各入口当前标识来源与 Job 持久载荷、重试/恢复语义；未顺带改成真实 Operation ID。
- [x] 运行相关现有测试、类型与触及代码规范检查、公开契约差异检查；仅补当前迁移确实缺失的回归，不删行为断言、不修无关基线失败。
- [x] 所有改动可追溯到本规格；没有新增依赖、迁移、公开功能、通用策略开关或无关清理。完成后同步项目进度，区分代码实现与真实验收。

## 验收证据要求

- **架构**：列出三入口保留的生命周期责任及已移入 Operation module 的执行知识，附调用关系与职责对照；文件/行数减少不替代 Depth 证明。
- **确定性行为**：记录测试命令、基线、结果及失败归属；通过原入口查询真实迁移 SQLite 的业务对象、Proposal、Operation、effect 与 Job，不只断言 helper 返回值。
- **竞态/恢复**：验证取消与提交交错、重试期间降档/目标修改、成功提交后重放、并发 Retry 和 Run 重启不重复。优先复用现有验收用例。
- **验证级别**：分别标明自动化、模型/网络替身、真实 API/SQLite/Worker、真实模型和真实 Tauri/WebView2；未做项保留未验证，不用历史绿灯或浏览器模拟替代本票证据。
