# 04 — 课程详情与编辑

**What to build:** 让学习者从真实列表进入课程 Overview，查看并编辑课程上下文；详情同时提供稳定的 Records 宿主，但诚实说明学习记录将在后续计划接入。

**Blocked by:** 02 — 首门课程持久化闭环.

**Status:** ready-for-agent

- [ ] 学习者可从列表进入课程详情，并查看名称、学习场景、教育阶段或学习深度、课程类型、说明和热词摘要。
- [ ] 详情路由使用真实课程 ID；不存在或已软删课程显示未找到状态及返回知识空间的路径。
- [ ] Overview 与 Records 使用受校验的 URL tab 状态，刷新后保持当前 tab。
- [ ] Records 只提供后续计划的稳定内容宿主并明确标示“未接入”，不显示假记录或把未实现功能描述为真实空列表。
- [ ] 学习者可以编辑课程名称、场景、阶段或深度、类型和说明；成功后列表与详情缓存同步刷新。
- [ ] 从 SCHOOL 切换到 CAREER/INTEREST 时必须填写有效深度并清空阶段；反向切换必须填写阶段并清空深度。
- [ ] 无效编辑在 API 边界被拒绝，旧数据保持不变；界面保留输入、聚焦错误字段并提供清楚说明。
- [ ] 编辑使用课程 PATCH 契约及 OpenAPI 生成类型，不增加一套专用手写 Course 模型。
- [ ] API/SQLite 集成测试覆盖详情、编辑、跨场景切换、清洗空白名称、404 和软删详情不可见。
- [ ] 前端行为测试通过可访问角色覆盖 tab、编辑成功、校验失败和保存失败重试。
- [ ] 真实 HTTP 与桌面渲染证明编辑落入 SQLite 并在刷新后保持；Query 缓存更新不能替代持久化证据。
