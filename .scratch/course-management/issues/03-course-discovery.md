# 03 — 课程搜索与筛选

**What to build:** 让学习者在真实课程列表中按名称子串、教育阶段和课程类型快速缩小范围，并能刷新、清除条件或从无匹配结果恢复。

**Blocked by:** 02 — 首门课程持久化闭环.

**Status:** ready-for-agent

- [ ] 课程列表支持名称搜索、教育阶段筛选、课程类型筛选以及三者组合使用。
- [ ] 名称搜索去除首尾空白并执行字面量子串匹配；`%`、`_` 和转义字符按普通输入处理，不成为数据库通配符。
- [ ] 搜索和筛选参数位于受校验的 URL 状态中，刷新页面后仍可恢复，不进入 Zustand。
- [ ] 有课程但无匹配结果时显示“没有匹配结果”，与尚未创建课程的真实空态明确区分。
- [ ] 学习者可以一次清除全部条件并恢复默认的最近更新排序列表。
- [ ] API 查询参数、OpenAPI 生成类型和前端调用保持单一契约，不新增重复手写类型。
- [ ] 所有列表查询恒定过滤已软删课程；组合条件不会使墓碑数据重新出现。
- [ ] 查询失败显示可理解的错误与重试动作，不用空数组伪装成功。
- [ ] API/SQLite 集成测试覆盖普通中文搜索、组合筛选、空白搜索、字面量 LIKE 转义、无匹配结果和软删过滤。
- [ ] 前端行为测试通过可访问角色操作搜索、筛选、清除和错误重试，不断言内部 state 或 CSS 类名。
- [ ] 真实桌面 Network 证明筛选请求命中 sidecar 且渲染结果来自真实 SQLite；静态测试或 mock 不作为集成通过依据。
