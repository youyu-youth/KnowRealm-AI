## 1. GLOSSARY.md：新增两个术语

位置：现有「学习状态」中的「模拟测试」之后，不改既有术语含义。

**计划练习（Plan Practice）**:
为某计划项发起的一轮独立作答，遵循已确认的练习要求，有自己的进度、答案和结果。计划练习结束、评分完成与计划项完成是不同状态。
_Avoid_: 模拟测试（课程级组卷）、普通习题作答（单题首次作答）

**练习要求（Practice Requirements）**:
用户确认的计划练习主题、题量、题型与资料来源范围；每轮计划练习遵循启动时固定的要求。
_Avoid_: 计划标题（只是初始意图）、生成提示词

这两个术语表达业务概念，不规定数据表、类名、API 或存储方式。

# 计划练习固定启动时要求与题面，独立保留作答及评分结果

Status: accepted（2026-10-17，计划项学习闭环 Grill 定稿；决策已批准，功能尚未实现）

计划项学习闭环需要支持中断继续、多轮练习及可解释的历史结果。若始终实时读取原题，修改、删除或移动来源会改变卷面或使既有轮次失效，重评也可能使用与作答时不同的依据。

**决定**：每轮计划练习固定启动时已确认的练习要求、题干、选项、题型、参考答案及解析等判分依据，独立保留作答、评分和来源追溯信息。已启动轮次不随计划要求或原题后续变化而换题；修改后的要求用于下一轮。原题或来源资料失效时，在所属目标与计划版本仍允许执行的前提下，既有轮次仍可继续并保留历史，但应标注来源失效并停止原资料入口；新练习只从当前允许且有效的来源取题。删除原资料后，既有练习仍保留其题目副本，来源清理不应被练习引用阻塞；课程本身删除时，练习随课程不可见。

计划项完成由用户确认，与练习结束、评分完成分别记录。部分评分显示覆盖数和成绩分母，仅重试未评分题并保留成功结果。真实作答沿用既有学习事件与证据链，题目副本本身、打开资料及勾选计划项完成都不构成新增掌握度证据；不修改 ADR-0021/ADR-0023 的消费和派生边界。

## Considered Options

| 方案                         | 取舍                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------- |
| 固定每轮要求、题面与判分依据 | 采纳；增加本地存储及清理兼容成本，换取练习可恢复、历史可解释与判分依据稳定。 |
| 始终实时引用原题             | 不采纳；副本少，但原题变化会使既有练习及历史结果不稳定。                     |
| 来源失效即终止已有练习       | 不采纳；减少保留副本的需要，但会中断已投入的学习，削弱继续学习能力。         |

## Consequences

- 固定题面是练习历史的一部分，不是新的可选库内习题或重新采纳的学习资产；保留副本的事实须在涉及删除和历史查看时清楚表达。
- 既有轮次固定的内容，不自动授权从失效来源创建新轮次，也不扩大其他课程、共享资料或网络的取题范围。
- 新增页面、API 与 Agent 查询仍遵守答案揭示时机；固定保存参考答案不意味着作答前可以读取答案。
- 页面和 Agent 复用领域服务及受控入口，遵循 ADR-0026 的授权、确认和回执机制；已确认练习要求不能替代某次写操作的执行授权。
- 本决定适用于计划练习。技术实现优先复用现有测试模块；既有模拟测试的兼容、必要迁移、来源外键及历史数据处理在规格中逐项明确，不据本 ADR 默默扩大行为变更。
