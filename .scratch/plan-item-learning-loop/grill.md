## 已确认决策

| 问题               | 决策                                                                                                                                                                                                                            |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Q1 首版类型        | 学习资料（STUDY_RECORD）与做习题（PRACTICE_QUIZ）；其余类型保留现有操作。                                                                                                                                                       |
| Q2 完成判定        | 展示实际学习/作答结果，始终由用户确认计划项完成；任务完成与知识掌握分别记录。                                                                                                                                                   |
| Q3 结果归属        | 只自动关联从计划项明确启动的学习；其他入口的历史学习可由用户手动确认完成，不追溯绑定。                                                                                                                                          |
| Q4 取题范围        | 绑定明确的一份或多份资料，使用其已采纳习题；结合 Q8 按计划项标题筛选相关题。                                                                                                                                                    |
| Q5 继续与重练      | 未结束的练习继续原进度；明确选择重新练习才创建新一轮并保留旧结果，不自动改变计划项完成状态。                                                                                                                                    |
| Q6 阅读恢复        | 恢复关联记录及上次内容页签；复用已有定位能力，不承诺新增精确页码、段落或播放位置恢复，不推断阅读百分比。                                                                                                                        |
| Q7 旧项启用        | 缺关联的旧计划项允许首次选择并确认资料范围后保存；系统/Agent 可推荐，用户确认绑定及后续范围变更。                                                                                                                               |
| Q8 相关性与数量    | 按计划项标题提取相关的真实题目；计划要求 N 题，提供 N 道不同的题，不以少题或重复题凑数。                                                                                                                                        |
| Q9 默认结果        | 展示最近启动的一轮及其进度/评分状态；旧轮结果独立可查，不跨轮拼接或冒用旧成绩。                                                                                                                                                 |
| Q10 真实题来源     | 首版只使用已有、已采纳习题；不临时生成或新增原始资料题目提取能力。                                                                                                                                                              |
| Q11 扩展来源       | 选定资料不足时可推荐本课程其他归属资料中的相关题，用户确认新增来源后才创建练习；不扩展到其他课程、共享引用资料或网络（共享范围见 Q14）。                                                                                        |
| Q12 数量消歧       | 计划未给题量或标题/正文数量冲突时，先请用户确认，再保存为该计划项的明确要求；匹配、建卷和结果使用同一数量。                                                                                                                     |
| Q13 首次确认       | 合并展示主题、数量和资料范围，一次确认后保存；后续直接开始或继续，要求变化时重新确认。                                                                                                                                          |
| Q14 共享资料       | 首版练习仅取本课程归属资料的已有习题；共享资料沿用现有只读阅读能力，不参与取题。                                                                                                                                                |
| Q15 题型           | 支持现有单选、多选、判断、填空、简答；指定题型时遵循要求，未指定时均可参与，不强制平均分配。                                                                                                                                    |
| Q16 评分失败       | 保留作答与已成功评分结果，仅重试未评分题；展示已答/总题、已评分/总题及成绩分母，未全部评分时标明部分成绩，评分失败不视为答错；计划完成仍由用户确认。                                                                            |
| Q17 执行中修改     | 已启动练习固定启动时的要求与题目，修改标题/题量/来源后确认的新要求仅用于下一轮；当前轮标注原要求，不中途加题或换题。                                                                                                            |
| Q18 已完成项       | 当前生效计划且目标进行中时，已完成项可继续阅读或主动重练；保持原完成状态与首次完成时间，不重复计数；历史版本及已完结目标仅查看历史结果。                                                                                        |
| Q19 来源失效       | 已创建练习保留启动时题面与判分依据，可继续及查看历史；原题/资料删除或移出课程时标注来源失效并停止原资料入口，新练习不从失效来源取题。原资料删除后旧练习仍保留题目副本，且不能阻碍原资料清理；课程自身删除时练习整体随课程隐藏。 |
| Q20 匹配与模型失败 | 保留已有练习和已确认题集；尚未完成主题匹配时不建练习，说明原因并可重试，不随机替换不相关题。简答无法评分时保留答案、显示待评、恢复后可重试；首版不另建人工选题界面。新练习仍受 Q19 的来源有效性检查。                           |
| Q21 Agent 接入     | 首版支持查看要求与结果、准备或继续练习、重试未评分题、确认计划项完成，实际阅读及答题由用户完成；与页面复用领域服务及事实源，参数有缺失/歧义时追问，写操作遵循现有授权/确认/回执。                                               |
| Q22 重练取题       | 按已确认要求重新选题，优先使用该计划项此前各轮未用过的相关题；新题不足时可复用旧题并提示，本轮仍须足量且不重复；新增来源仍先确认。                                                                                              |
| Q23 未交卷时重练   | 每个计划项最多一轮可继续作答的练习；明确重练时提示已有进度，用户确认后才将旧轮标为已放弃并保留答案与结果，开启新轮；新轮准备失败时旧轮仍可继续。已交卷旧轮继续评分，不占可作答轮次。                                            |

Q8、Q10、Q11 的合并约束：本课允许来源中不足 N 道相关题时，不创建该轮练习；展示缺口并等待用户补充可用题或明确调整要求。

## 汇总

- 最小闭环：从计划项打开资料并恢复页签，或按已确认要求创建/继续计划练习；返回本次结果，由用户确认计划项完成。
- 练习要求包括主题、精确题量、题型与资料范围；主题取自计划标题并经确认，只使用本课程归属资料的已采纳习题。要求 N 题则提供 N 道相关且不同的题，匹配失败或不足时明确反馈、不建卷。
- 每轮固定启动时题面与判分依据，结果独立保存。来源失效不破坏已有轮次，新的练习仍校验来源可用性。
- 计划完成、练习结束、评分完成与概念掌握分别表达。优先展示最近启动的一轮；部分评分显示覆盖数与分母，只重试未评分题。
- 页面与 Agent 共用业务结果和受控入口；新增能力按当前授权、外发同意与回执规则接入。
- 复用现有计划、记录详情、测试作答/评分/恢复、JobRunner 和学习证据链。净新增为要求确认与关联、主题/资料定向选题及精确数量、轮次固定内容、部分评分重试、计划执行入口与 Agent 能力。
- 本次不包含自适应重排、概念复习/自由任务闭环、共享资料取题、网络取题、临时生成新题、原始资料题目提取、人工选题界面或新增精确阅读位置恢复。

## 核心验收场景（待规格细化，尚未执行）

1. 旧计划项首次确认主题、数量、题型与来源；缺题量或数量冲突时先消歧，要求在页面和 Agent 查询中一致。
2. 要求 15 题时，创建恰好 15 道相关且不同的已采纳题；来源扩展先确认，题少、匹配失败、模型不可用时不创建伪成功结果。
3. 中断、重启后继续同一轮；重复启动不新建重复轮次。明确重练才开启新轮，新轮准备失败仍可继续旧轮。
4. 进行中修改要求不改当前题面；原题修改、删除或来源移动后，旧轮的题面与判分依据稳定，来源失效标注准确，原资料清理可完成。
5. 五题型与部分分数如实展示；部分评分失败保留答案和成功结果，仅重试未评分题，重试不重复写学习事实。尚未评分时不显示伪完整成绩。
6. 人工完成只记一次首次完成事实；主动重练不撤销完成或重复计数，历史版本及完结目标遵守只读边界。
7. 阅读进入正确记录并恢复页签；打开资料不冒充读完或掌握，关联资料失效时给出明确反馈。其他入口学习不自动冒认成本次结果。
8. 页面与 Agent 复用相同要求、结果及权限约束；确认绑定对象与参数，取消/降权/版本变化在提交处校验，异步准备和评分区分受理/执行/完成并可查询恢复。未到揭示时机的参考答案不通过新增页面/API/Tool 提前暴露。
9. 用现有自动化及真实 API/SQLite 验证数据与恢复；模型匹配/评分质量、真实模型失败及原生桌面多主题/键盘/窄窗/系统缩放分别验收，不相互替代。
