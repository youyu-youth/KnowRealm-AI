# 01: 资料学习与返回计划闭环

Status: ready-for-human
批准日期：2026-10-17

依据：[定稿规格](../spec.md)、[Grill 决策](../grill.md)、[批准的拆分与共用约束](../tickets-proposal.md)。
每票负责本业务闭环所需的领域、HTTP、页面、Agent 与定向验收；先阅读规格及共用约束，保留既有业务行为。

**What to build:** 用户从资料类计划项直接进入明确关联的记录，恢复页签，返回原计划项查看本次启动事实并人工确认完成。旧计划可首次补齐关联，页面与 Agent 使用同一结果。

**Blocked by:** None (can start immediately)。

**规格覆盖：** 用户故事 1～6、40、42～44，以及资料学习对应的 Agent/可访问性约束。

- [x] 旧项可推荐或选择资料，确认后保存；校验计划项类型、课程、记录可见性及现有共享只读边界，不能按标题静默绑定或扩大访问权限（真实 HTTP/SQLite＋页面集成）。
- [x] 从计划明确启动后才记录该计划项的本次访问及页签，返回入口准确；其他入口的访问不回填成本次结果，不显示伪阅读百分比或真实学习时长（真实 HTTP/SQLite＋页面集成）。
- [x] 可恢复已有记录页签；记录失效时给出原因及重新关联路径，不保留可点击的失效来源入口。历史版本、完结目标及已跳过项的执行限制由服务端和页面共同遵守（真实 HTTP/SQLite＋页面集成）。
- [x] 当前生效计划且目标进行中时，已完成资料项仍可打开；人工完成复用现有入口，首次完成时间、今日完成投影及掌握度边界正确，重复操作不重复计数（真实 HTTP/SQLite；今日投影及零掌握度写入断言）。
- [x] Agent 可查询该项关联/学习状态、提出需确认的关联变更并返回准确站内入口；写侧走现有受控 Operation、授权、版本及取消校验，不由模型代读或声称读完（已装配 Tool＋模型替身确认框架，真实模型另验）。
- [x] 真实 HTTP＋SQLite 验证关联、启动、页签、失效及首次完成事实；页面集成验证返回、焦点及缓存刷新。已有计划编辑/完成语义的相关测试保持通过（自动化与浏览器层，证据见实施记录）。
- [ ] 真实模型意图理解、Tauri/WebView2、Windows 系统缩放及屏幕阅读器，由 05 汇总验收，本票未代勾。

**桌面复验路径：** 隔离目录中准备一个已关联项与一个缺关联旧项；分别补齐关联、打开记录、切换页签、返回并再次打开、人工完成、从其他入口访问，再验证本次归属与完成数量。记录主题、视口、DPR、系统缩放及恢复方式；原生复验由 05 汇总执行，不以页面替身测试代勾。
