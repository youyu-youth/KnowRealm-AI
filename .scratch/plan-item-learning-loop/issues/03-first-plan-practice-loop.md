# 03: 首轮计划练习与人工完成闭环

Status: ready-for-agent
批准日期：2026-10-17

依据：[定稿规格](../spec.md)、[Grill 决策](../grill.md)、[批准的拆分与共用约束](../tickets-proposal.md)。
每票负责本业务闭环所需的领域、HTTP、页面、Agent 与定向验收；先阅读规格及共用约束，保留既有业务行为。

**What to build:** 用户使用 02 准备的题集开始一轮独立计划练习，在现有作答界面完成五题型、交卷并查看结果，再返回计划人工确认完成；中断后可继续，题面及判分依据不受来源变化影响。

**Blocked by:** [02：练习要求确认、精确取题与缺题补源](./02-practice-requirements-and-selection.md)。

**规格覆盖：** 用户故事 9、19～27、34、39～40、44～48。

- [ ] 从真实准备结果建卷，提交时重验要求修订、候选题版本/状态、授权及取消；题集过期或不足时不建卷，不允许跳过 02 的已确认要求和来源范围。
- [ ] 复用现有独立作答与评分能力，明确区分计划练习用途，保存轮次关联、启动顺序、完整题面/判分依据、追溯及概念归属。普通习题首次作答和普通模拟测试保持兼容，不复制新的测试引擎。
- [ ] 复用现有作答界面接通五题型、答案持久化、交卷及正常评分；计划返回入口和本轮状态准确，评分执行状态与评分完整性分开，基础结果显示已答/已评分/总题及分母，不能只显示一个整卷结束状态。
- [ ] 重复开始、请求重放、两个并发入口及应用重启均返回同一轮；数据库约束与事务保证每项最多一轮可作答，正在评分时普通开始返回状态，不自动创建下一轮。
- [ ] 当前轮固定题面、要求及判分依据；修改计划要求或原题不改变当前轮。来源修改、删除、移出课程及实际清理后，已有题面和评分仍可用，失效来源有标注且不可跳转，新练习拒用失效来源。
- [ ] 必要迁移与来源引用清理随本票交付，不让新增练习引用阻塞资料删除；不猜测回填旧试卷，不顺带全面改造既有测试清理。课程删除仍整体不可见。
- [ ] 人工完成保持首次完成事实，练习和评分不自动完成计划项；真实作答沿既有事件消费链，准备/副本/完成不制造额外掌握度证据；未揭示阶段的答案不从新页面/API/Tool 泄露。
- [ ] Agent 可准备后开始/继续、查询当前轮及结果、返回入口并复用现有完成能力，真实用户作答仍在页面；受控执行回执及直接调用旧作答入口都遵守计划版本/目标约束。
- [ ] 真实 HTTP/SQLite/Worker 验证从 15 题准备到首轮建卷、作答、正常评分及人工完成，补页面集成与相关 Agent 链路验收；覆盖中断重启、重复提交、来源清理、旧模拟测试兼容和题面保护。

**桌面复验路径：** 完成 02 的 15 题准备，开始后答到 6/15，离开并重启继续，交卷查看结果并回计划确认完成；另在隔离来源中修改、删除/移动原题资料后验证固定题面与失效提示。记录轮次、题集、要求修订、完成时间和事件数。
