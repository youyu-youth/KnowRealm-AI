# 04: 评分失败恢复、安全重练与多轮结果

Status: ready-for-human
批准日期：2026-10-17

依据：[定稿规格](../spec.md)、[Grill 决策](../grill.md)、[批准的拆分与共用约束](../tickets-proposal.md)。
每票负责本业务闭环所需的领域、HTTP、页面、Agent 与定向验收；先阅读规格及共用约束，保留既有业务行为。

**What to build:** 用户看到准确的评分覆盖和部分成绩，只重试未评分题；明确重练时优先选此前未用过的相关题，安全切换可作答轮次并保留历史，最近轮结果与首次计划完成事实保持独立。

**Blocked by:** [03：首轮计划练习与人工完成闭环](./03-first-plan-practice-loop.md)。

**规格覆盖：** 用户故事 22～23、28～38、41～43，以及 39、44、46、48 的评分/重练分支。

本票复用 03 的固定题面、轮次约束、真实作答与基础结果；新增范围仅为失败重试及轮次切换。两个检查点分别验收，并共同验证旧轮晚到评分不改变默认轮次，避免遗漏状态交互。

以下勾选仅表示本票实现及自动化接缝通过（真实生产路由/迁移 SQLite/Worker，外部模型替身；页面为 DOM/MSW/Router）。真实模型、原生桌面和系统缩放另列未执行项，不随实现完成勾选。证据见 [04 实施与验收](../04-implementation.md)。

### 检查点一：部分评分失败与定向重试

- [x] 包括整轮已结束但仍有未评分题的计划练习，都能显示已答、已评分、未评分、总题量、错误与重试入口；不能只允许整轮评分失败状态重试。
- [x] 成绩沿用逐题分数等权平均，支持部分分数；未全部评分明确标注部分成绩与实际分母，零已评分无成绩，失败不按答错记账。
- [x] 只允许已交卷轮次重试，已有评分任务返回其状态；每次只领取尚未评分题并使用固定判分依据，成功结果和用户答案保持不变，不提前揭示未交卷答案。
- [x] 重复重试、并发、取消、超时、重启及 Worker 恢复不重复评分成功题或写入同一学习事实；模型不可用时答案和结果持久保留，恢复后可继续。
- [x] 页面与 Agent 的重试入口复用同一授权、状态校验及任务回执；历史版本/完结目标不通过新入口开启用户评分操作，已受理任务保留实际后台收尾结果。
- [x] 真实 API/SQLite/Worker 使用可控的单题失败、部分分数和整体异常模型，验证从缺口到定向重试完成的持久结果及学习事件幂等；页面验证分母、错误及刷新，不扩大普通模拟测试的行为变更范围。

### 检查点二：安全重练与历史结果

- [x] 重练沿已确认的主题/数量/来源/题型重新取题，优先本项此前各轮未使用的合格题，新题不足可提示复用旧题，本轮仍足量且不重复；不能为了换题自动扩源。
- [x] 有未交卷旧轮时先展示已答进度和放弃影响，用户明确确认后再准备新轮；新题集校验成功后，在同一提交事务中放弃旧轮并创建新轮。
- [x] 准备失败、取消、要求/来源变化或旧轮基线过期均不能丢失旧答案、提前放弃或新增第二个可作答轮；重复请求与并发重练幂等。
- [x] 旧轮结果及要求固定可查，当前轮标明原要求；修改后的已确认要求仅用于下一轮，重练不覆盖历史。已交卷旧轮继续评分，不占可作答轮次。
- [x] 默认结果按最近启动轮次选择，旧轮延迟评分不能抢回当前展示；每轮进度、分母和成绩独立，不跨轮拼接或冒用最高分。
- [x] 当前生效计划且目标进行中时，已完成项可继续/重练但不改变首次完成时间、完成数量、估时或直接改掌握度；历史版本、完结目标及跳过项在所有入口遵守只读/不可执行边界。
- [x] 页面与 Agent 均可明确重练、确认放弃影响、查询历史及继续当前轮；沿用现有授权和回执，评分重试直接复用本票前一检查点，不重复实现。
- [x] 真实 API/SQLite/Worker 验证 6/15 时重练成功、失败保留旧轮、优先新题/复用、两个并发请求、已完成项及旧轮晚到评分；页面验证历史切换、返回及缓存同步。

**桌面复验路径：** 准备包含简答题的 15 题练习，制造“已答 15/15、已评分 13/15”，查看部分成绩后重试；记录成功题评分与事件在重试前后不变，另验证零题评分、重复请求和离开恢复。真实供应商验证由 05 单列。 一轮答到 6/15 后触发重练，先取消确认，再制造准备失败，最后成功开启新轮；对比旧答案、可作答轮数和来源。完成计划项后再重练，验证首次完成事实保持不变；让旧轮评分延迟返回，检查默认展示仍为新轮。
