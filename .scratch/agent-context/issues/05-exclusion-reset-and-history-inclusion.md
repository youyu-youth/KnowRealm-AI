# 05: 排除、重置与旧历史纳入

**What to build:** 用户在独立页面或聊天中持续排除/恢复轮次与资料来源，重置后开启新上下文段，并明确选择旧历史重新纳入；这些选择同时作用于后续摘要、材料检索和历史取回，保留原数据及后台任务。

**Blocked by:** 04 — 固定内容与来源有效性。

**Status:** ready-for-human

依据：[规格](../spec.md)的实施决策 2、5、7～9、11；主要覆盖 C10～C14，并将 C05/C15/C16/C17/C19 的全部过滤和版本组合闭环。

## 交付边界

依赖已实现的摘要、读取、固定及授权路径，交付排除/恢复、重置和显式旧历史纳入的真实持久操作。将统一会话过滤贯通所有已存在消费入口，而非只隐藏页面行或只修改下一次初始 Prompt。

## 验收清单

以下已勾选范围为自动化、HTTP ASGI/真实迁移 SQLite/JobRunner/Worker（供应商模型替身）及前端 API 替身；视觉只限浏览器普通字号模拟。证据与完整运行状态见 [05-implementation.md](../05-implementation.md)，不代表真实模型/Tauri 验收完成。

- [x] 排除明确轮次或资料来源后，后续组装、分块摘要及重建、领域检索和历史/输出取回共同遵守；原消息和资料不删除，用户可恢复。
- [x] 排除按可追溯身份实现，不声称可消除其他消息里无来源标记的转述；系统规则和执行端权限校验不能被移除。
- [x] 排除优先于固定，冲突固定项保留但暂停注入并给原因；恢复后重验有效性；再次固定被排除来源不能偷偷恢复它。
- [x] 重置开启持久新段，旧段仍可查看但不自动注入或被模型取回；清空旧承接与有效摘要，保留固定、排除、材料范围和独立长期记忆。
- [x] 明确纳入旧历史需要选择合法范围，受原排除/来源有效性和当前会话归属约束，不默认全部恢复；缺范围追问，非法或过期范围拒绝。
- [x] 排除、恢复、重置和纳入旧历史均按单会话可恢复 L1 接入既有三档、确认卡、版本及回执；页面显式动作复用 Service，不造绕过执行校验的写路径。
- [x] 设置从下一轮生效，当前轮使用原快照；页面明确显示当前实际输入与下一轮变更，重置不隐式取消独立 Run、不改变授权，未结束任务状态仍真实可见。
- [x] 新设置版本下有关摘要不可继续激活；重置/排除与迟到分块、取消交错通过。claim 接管沿原提交闸门，全量既有接管回归通过；没有声称枚举全部并发排列。
- [x] 旧轮快照的合法派生输入仅服务该轮，不能写回新段有效摘要；来源失效后旧缓存、工具结果及历史取回不能成为绕过途径。
- [x] 页面 API 流程验证排除/恢复、固定暂停、重置说明和纳入范围；确认/回执与失败冲突按返回结果呈现。四主题、zh/en、普通字号窄窗和键盘由浏览器模拟验证。
- [x] 真实 SQLite/Worker 验证设置提交、分块/激活与重置/排除/取消的交错，重开 lifespan 后段和规则不丢；公开读取验证旧段拒绝、显式纳入、查询游标和完整预算。
- [x] 三档授权、过期确认、后台任务保留、原消息保留、记忆外发开/关和既有资料范围回归通过；API/类型/错误登记与前端查询失效同步。
- [ ] 真实模型语义/usage、真实 Tauri/WebView2、Windows 125%/150%/200% 缩放与完整升级/备份组合留 06。200% 根字号模拟的正文可用高度问题未判通过，已有窄窗壳标题栏裁切仍保留。

## 完成证据

展示“固定片段→排除来源→重置→明确纳入旧轮”的完整流程，分别证明页面状态、模型真实可见投影、只读取回和持久事实；已完成自动化不代勾 06 的真实模型与桌面验收。
