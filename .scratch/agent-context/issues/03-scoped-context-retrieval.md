# 03: 历史、材料和工具结果受限取回

**What to build:** 用户追问被摘要省略的细节时，Agent 能在当前会话和上下文段内找回原消息、相关材料或大工具结果，限长分段读取并保留来源；用户也能从独立页面查看对应定位，不必开放任意文件权限。

**Blocked by:** 02 — 自动摘要、额度与持久恢复。

**Status:** ready-for-agent

依据：[规格](../spec.md)的实施决策 4、8～10、12；主要覆盖 C15 的会话/段/来源及预算边界、C20 的输出生命周期；延伸 C02/C04/C05/C18/C19。

## 交付边界

以 02 已有摘要覆盖、原消息和来源身份为依据，交付原文取回的 Tool、共用 Service、API、来源定位与实际模型输入闭环。资料优先复用领域检索/读取；无法重建的工具正文才持久保存受控输出。本票处理取回和输出有效性，不添加用户固定/排除入口。

## 验收清单

- [ ] 历史查找/读取默认限定当前会话和当前段；程序校验消息、轮次、来源及输出所属关系，错误身份不能跨会话、跨段或越权访问。
- [ ] 历史和工具输出支持预算内限长读取、稳定继续游标与剩余说明，非法/过期游标明确反馈；结果不丢工具配对、来源版本或定位。
- [ ] 原业务事实或资料优先用现有领域读取重建；不可重建临时工具结果按本会话及逻辑调用身份保存受控快照，恢复不重复写入或伪造旧正文。
- [ ] 小材料预算允许时仍可全文，放不下改用相关片段；保证历史承接优先，不用整份材料挤掉全部对话，也不为填满窗口加载无关内容。
- [ ] RECORD/LIBRARY_ITEM/COURSE/ALL 的资料及共享引用规则保持，来源删除、归档、版本变化或越界后正确拒绝/标记失效，摘要原文引用继续经证据定位校验。
- [ ] 模型取回属于只读工具并计入现有调用次数，输出参与每次完整请求预算；网页或 Tool 参数不能扩大读取范围，页面普通只读查询不占 Agent 工具次数。
- [ ] 通过公开配置关闭卸载却无可见读取工具的框架行为；超大结果有可用受控读取路径，不返回无法取回的文件指针、不开放任意文件/Shell/SQL。
- [ ] 模型可见选材不修改原业务结果、回执或已持久字符消费；大 JSON 与回执保持有效，前端源文查看与 Agent 取回使用同一归属/有效性口径。
- [ ] 有效摘要、取回或活跃恢复仍引用的输出不能提前清理；会话删除/失效后 API 不可读取，备份迁移保持数据引用，不另建独立文件服务或记忆库。
- [ ] 独立页面提供摘要来源与片段定位、无结果/未就绪/失效/预算耗尽反馈，键盘及主题可达；普通历史查找不触发上下文设置或长期记忆写操作。
- [ ] 真实 API/SQLite/框架工具路径验证跨会话拒绝、段边界、继续读取、次数/输入耗尽、故障恢复及会话生命周期；既有资料检索和引用回归、类型/契约/错误双语门禁通过。

## 完成证据

展示一条已压缩会话通过 Tool 实际取回原消息，以及一个不可重建大输出的限长读取；明确旧记录缺失正文时无法取回，不能编造。05 将在该已闭环读取入口加入用户排除及旧历史显式纳入。
