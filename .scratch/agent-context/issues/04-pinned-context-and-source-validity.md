# 04: 固定内容与来源有效性

**What to build:** 用户在独立页面或通过自然语言固定明确约束、关键决定、消息和资料片段，下一轮始终保留有效固定内容；来源过期、失效或固定过多时看到准确提示，可更新或解除。

**Blocked by:** 03 — 历史、材料和工具结果受限取回。

**Status:** ready-for-agent

依据：[规格](../spec.md)的实施决策 2、4、7～9、11；主要覆盖 C09、C12、C14，延伸 C03/C05/C13/C15/C17/C19。

## 交付边界

在已有真实压缩、原文取回和独立页面之上，交付固定/解除的持久设置、来源绑定、L1 Tool/操作注册、确认卡、直执行回执、页面编辑及下一轮输入。页面和 Agent 共用领域 Service，不能一条路径实际生效而另一条只是本地示意。

## 验收清单

- [ ] 可固定当前会话内的明确短文本、约束、决定、消息或资料片段，来源关联真实身份；对象选择、定位或范围不明确时追问，不猜测目标。
- [ ] 固定资料对象代表优先取材，正文仍受预算控制；有效短文本/片段不被压缩、自动裁掉或复制为长期记忆，不能扩大资料或会话作用域。
- [ ] 固定内容过多不可容纳时模型不出网，页面及聊天给出解除/调整动作；不靠提高窗口、截断固定内容或删除当前提问绕过限制。
- [ ] 固定片段绑定来源版本，原文变化标过期并暂停旧片段自动注入，允许用户更新或解除；固定对象从当前有效版本选材。
- [ ] 删除、归档、移出范围的来源不继续注入，关联摘要按来源失效或重建；固定条目保留原因供处理，原会话挂载对象失效仍拒绝发送。
- [ ] 固定/解除按单会话可恢复 L1 复用现有三档、Proposal 和 Operation；默认确认卡，其他档位按既有规则，执行端校验参数、对象、版本、身份、取消及授权。
- [ ] 确认绑定目标和预期版本，过期确认不覆盖新设置；自动摘要不创建固定项，也不能把摘要“已同意”作为授权；来源原文不是指令。
- [ ] 页面显式固定/解除与 Agent 路径调用同一 Service，返回持久新版本及结果；页面可查看条目、来源、有效/过期原因和实际注入状态，不混淆下一轮配置。
- [ ] 变更只在下一轮生效；正在运行或恢复的轮次沿原快照，不被页面设置静默改变，旧轮计算结果不能覆盖新版本；立即改变需要显式停止当前轮。
- [ ] 本轮固定内容优先保留，独立规则/Learner Context/固定块不重复进入摘要；分栏摘要与工具读取的来源验证继续生效。
- [ ] 通过真实 API/SQLite/Worker 和三档工具执行验证确认/直执行、固定超限、来源变化、迟到写入及版本竞争；前端完成页面操作、确认卡和实际输入查询闭环，相关回归及契约门禁通过。

## 完成证据

展示超过十轮或经历摘要后首轮约束仍以固定原文进入模型的证据，同时记录未固定摘要的语义局限。固定与排除冲突的用户行为由 05 交付，不提前增加排除入口。
