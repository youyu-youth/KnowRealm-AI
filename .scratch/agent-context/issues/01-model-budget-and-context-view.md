# 01: 模型预算与独立页面查看

**What to build:** 用户可配置实际模型能力，在聊天中发送问题时受到覆盖每次完整模型请求的输入预算约束，并从标题栏进入独立页面查看本轮实际输入概要与下一轮预估；离开和返回聊天不丢草稿、不停止生成。

**Blocked by:** None (can start immediately).

**Status:** done

依据：[规格](../spec.md)的实施决策 1～4、8、11～12；主要覆盖 C01、C02、C03 的基础预算、C17，以及 C12/C18/C19 的初始快照、兼容和同意边界。

## 交付边界

从供应商能力配置、持久策略/轮次输入记录、公开 HTTP 契约和模型调用 Middleware，到真实独立页面查看与聊天返回形成完整路径。现有上下文 Service、系统提示注入、ChatTurn 与组件优先复用，不先创建通用平台或纯基础重构。

本票建立最终输入闸门及本地会话状态的最小必要结构；摘要与替代十轮窗口由 02 接入，取回与设置管理由后续票接入。不提前展示未实现的压缩/设置成功状态，也不单独放开历史窗口导致未摘要内容丢失。

## 验收清单

- [x] 能力配置区分输入、输出及总窗口，绑定端点和模型；可信值自动提供并标来源，覆盖优先，未知或自定义部署需配置，不猜测同名模型窗口。
- [x] 回答输出默认 4096 Token、摘要默认 1024 Token 可配置；按已知能力收紧，必要输入和输出不能共存时明确拒绝，不伪造能力。
- [x] 每次实际主模型调用前检查最终系统提示、工具 schema、协议开销、消息、材料及同轮工具结果；检查后无未计量追加。可靠适配/近似计数分别留 10%/20% 余量，不能用字符限额冒充精确 Token。
- [x] 不能容纳的请求无实际模型调用；必要工具配对、当前提问、业务 JSON 和回执保持完整；原工具次数、字符与业务提交预算不被重置或替代。
- [x] 请求前持久绑定策略、能力和输入版本；公开查询区分实际已调用快照与下一轮预估，缺失供应商 usage 显示未知，不填零。
- [x] 聊天标题栏进入独立管理路由并带当前会话，页内可切换、返回；不增加侧栏一级入口，不把独立页面替换为右栏/Sheet，不混合会话内容。
- [x] 页面可查看预算来源、占用、输出预留、余量及错误恢复指引；所有现有主题、窄窗、键盘、zh/en 与 reduced-motion 适配，复用现有组件和语义变量。
- [x] 按会话保存未发送草稿，往返或切换后不丢失、不串会话、不放 URL；离开仅关闭订阅，生成继续，返回通过活动轮次恢复观察。
- [x] 旧会话按需初始化，升级迁移不调用模型、不重写历史；旧非终态轮次保留安全兼容协议，不能套新策略重建原输入或恢复成零消耗。
- [x] 供应商变更、外发同意和记忆外发开关遵守既有规则；日志不新增完整 Prompt、材料或记忆正文。
- [x] 通过公开提交/查询/取消/恢复入口、真实迁移 SQLite/Worker 和模型替身验证完整输入；复用相关前端导航/草稿测试，触及类型、规范、错误登记、双语及 OpenAPI 契约一致。
