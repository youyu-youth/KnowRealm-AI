# Agent 上下文设计汇总

日期：2026-10-12
状态：Q1～Q30 已确认；用户明确调用 to-spec、to-tickets，已转为 [spec.md](spec.md)并发布[六张工单](issues/README.md)；未进入实现。
决策依据：[grill.md](grill.md)。本文件为设计汇总，不是实施规格或工单。
约束：不主动调用 to-spec、to-tickets；不修改编码规范。权威文档增补先呈现提案。

## 目标与范围

解决长对话早期信息消失、完整模型输入缺少统一预算，以及用户无法管理上下文的问题。
覆盖所有现有 Agent 会话范围及模式，保持资料作用域、证据引用、受控执行和外发同意。
管理对象是单个聊天会话；首版不增加跨会话共享上下文，不替代学习者长期记忆。

## 核心模型与职责

| 对象 | 职责与边界 |
| --- | --- |
| 会话上下文设置 | 固定项、排除项、历史段边界，属于用户可修改的本地会话状态 |
| 上下文段 | 重置后开启的历史承接范围；旧段仍可查看，默认不能自动取回 |
| 会话摘要 | 带原消息来源、覆盖范围和版本的派生内容，可重建，不是授权或资料原文 |
| 固定项 | 保留明确约束、决定、消息或片段；资料对象固定表示优先选用，不保证全文注入 |
| 排除项 | 当前会话禁止后续自动使用的轮次或资料来源，可恢复，原始数据保留 |
| 轮次上下文快照 | 本轮实际使用的设置版本、摘要版本及恢复所需输入；与下一轮设置分开 |
| Checkpoint | 当轮框架运行态；不替代会话设置、长期记忆或业务执行事实 |

后端在现有 Agent 模块内集中上下文业务职责，前端不计算最终预算或直接读写数据库。
继续复用领域 Service、检索、轮次 worker、操作注册表、事件与用量日志，不新建 Agent 平台。

## 预算规则

- 每次主模型调用前检查最终模型可见请求：系统提示、工具定义、消息、材料和工具结果。
- 摘要调用也独立检查输入预算与输出额度；不能靠主回答预算间接保证。
- 能力元信息可信时自动提供，用户可覆盖；自定义端点不能只靠同名模型推断窗口，信息不足需配置。
- 输入上限、输出上限、总窗口分别解释；同时满足已知约束，避免将 SDK max_input_tokens 无条件当作总窗口。
- 普通回答默认输出上限 4096 Token，摘要默认 1024 Token，可调整，小窗口按能力收紧。
- 可靠计数适配预留 10% 安全余量；近似计数预留 20%。界面说明计量为估算或适配值。
- 输入占用达到可用预算 80% 时压缩，目标降至 60%；目标不能达到但仍安全可继续，硬预算超限阻止调用。
- 取消固定 10 轮硬窗口，按预算保留近期完整往返，工具调用与结果保持合法配对。
- 已有工具次数预算继续独立约束；完整请求预算不能代替调用次数及业务提交预算。

必需规则、工具定义、当前提问、有效固定内容和当前工具闭环信息优先；其次摘要及近期轮次；其后材料片段和较早工具细节。
优先级影响预算紧张时如何选材，不要求为无关内容填满剩余窗口。
小材料可保留全文注入；放不下改为有来源的片段读取，不把历史承接全部挤掉。

## 摘要与压缩

- 采用已有摘要加新增待压缩内容的增量处理，覆盖当前段全部待压缩输入，过长分块。
- 固定栏目：目标、明确约束、已确认决定、相关对象与来源、未完成事项、待澄清问题。
- 摘要覆盖历史及必要工具结果；不复制独立的系统规则、固定块、学习者记忆块或整份原始资料。
- 每条摘要信息保留可追溯来源；原始消息保留，摘要不能当作逐字证据或执行许可。
- 摘要输出须通过栏目结构、覆盖范围和来源归属校验；模型不能自行扩充有效来源或修改程序记录的处理范围。
- 使用当前会话模型与供应商，遵守现有外发同意，摘要与回答分别记录用量。
- 一次自动压缩最多 4 次摘要请求，含重试；恢复不重置计数。
- 超过额度保存进度并停止本轮，由用户明确继续才追加额度；未覆盖全部材料不激活摘要。
- 分块可暂存，整批成功且版本、来源和执行身份有效时才原子激活；失败不替换原有效摘要。
- 模型可能遗漏语义，原文覆盖不代表无损总结；重要约束可固定并直接保留。

框架可复用计数接缝、触发能力和工具安全切点；不能仅启用默认摘要件就视为完成。
跨轮摘要持久化、全量材料覆盖和压缩后最终预算检查由产品层补齐，避免依赖 SDK 私有实现。

## 固定、排除、重置

- 所有调整从下一轮生效；当前轮沿用快照，要立即改变须先停止当前轮。
- 固定短文本与片段不自动裁掉；固定过多无法容纳时明确提示，不无限扩张预算。
- 固定片段绑定来源版本，原文变化标过期，用户更新或解除；固定对象按当前有效版本选材。
- 来源删除、归档或离开访问范围后停止注入，相关摘要失效或重建；原挂载对象失效沿用拒绝发送规则。
- 排除约束后续组装、摘要及检索；排除优先于固定，冲突固定项保留并显示暂停原因。
- 按可追溯来源过滤；其他消息里缺少来源标记的转述无法保证自动识别并清除。
- 重置开启新上下文段，清掉历史承接与摘要，保留固定、排除、材料范围和独立长期记忆。
- 旧段重纳入需用户明确选择范围，仍遵守排除；后台任务和既有授权不因上下文重置被取消或扩大。
- 未结束任务的真实状态继续提示，防止重置上下文后误认为业务从未发生。

## Agent 与页面共用入口

读取能力：查看会话上下文状态、受限查找/读取历史，以及按来源读取必要资料或工具输出。
修改能力：固定/解除、排除/恢复、重置以及明确重新纳入历史范围。
具体 API 路径与 Tool 名称在实现前核对既有命名；这里不把建议名当作已存在接口。

- 读取默认仅当前会话、当前段，校验所属关系和排除，按预算限长并支持继续读取。
- 资料优先复用领域读取入口；不可重建临时输出以受控本地快照承载，不开放任意文件或 Shell。
- 关闭框架当前卸载却缺少可见读取工具的行为，通过公开中间件配置完成。
- 读取计入工具次数和完整请求预算；输出再次参与主模型调用前检查。
- 会话设置操作按单会话可恢复 L1 复用现有三档、提案、执行端校验及回执；默认档确认后执行。
- 页面直接编辑表达用户动作，与 Agent 提案/自动档共同调用领域 Service，保留版本及结果校验。
- 信息不足时追问目标项或历史范围，参数中的 session_id、对象归属与有效性由程序校验。
- 自动摘要仅维护派生状态，不能改变用户固定/排除规则，不能从摘要推导授权。

## 一次执行的完整路径

1. 用户提交提问，沿用持久受理与及时展示用户消息的链路。
2. 执行端读取有效会话设置、段、材料和摘要，绑定本轮版本并组装输入。
3. 在实际主模型请求前统一计量；按规则选材和按需压缩，摘要请求同样受预算、额度和取消控制。
4. 激活有效摘要后重新检查完整请求，再调用主模型。
5. 工具经原受控入口执行，结果保留来源和身份；下一次模型请求重新检查预算。
6. 过程、实际输入概要与用量经轮次事实和事件投影到聊天及管理页；完成后沿用现有收口。

## 失败、恢复与本地持久化

- 瞬时摘要错误自动重试最多 1 次，恢复不重置；配置、同意或额度错误直接反馈。
- 摘要失败保留原内容；仍安全则提示降级继续，否则停止本轮。
- 主模型真实超限最多缩减后重试该次请求 1 次，不重放已提交工具、不删除固定项。
- 用户取消后不自动续跑；崩溃恢复可复用完成分块，但须重验版本、来源、执行身份与当前权限。
- 用户设定变更、取消、来源失效后，旧计算的迟到结果不得覆盖新状态或成为下一轮有效摘要。
- SQLite 保存会话设置、段边界、摘要及覆盖/来源版本；checkpoint 继续承载当轮状态。
- 本轮恢复沿用原输入快照，权限及外发同意仍经执行端校验，快照不豁免现有门禁。
- 日志保留计量、版本、阶段与失败码，不额外记录完整 Prompt、材料或记忆正文。
- 派生摘要和临时输出按会话所属关系管理，不能绕过会话删除或来源有效性检查；清理复用现有本地数据生命周期，不另设独立文件目录和通用记忆库。

## 独立页面交互

入口位于聊天标题栏，带当前会话进入；页面内可切换会话，有明确的返回聊天路径，无侧栏一级入口。
页面必须标明所管理会话，不混合不同会话内容。

| 区域 | 内容与操作 |
| --- | --- |
| 概要 | 当前会话、材料范围、预算来源、计量方式、压缩阶段及恢复动作 |
| 本轮实际使用 | 轮次与上下文版本、实际选材概要、摘要及来源、固定注入情况、用量 |
| 下一轮设置 | 固定、排除、重置边界和变更生效提示；支持查看、恢复和调整 |
| 按需详情 | 摘要栏目、覆盖历史、来源定位、过期原因、分块进度及独立摘要用量 |

预计输入必须标作预估，未发生的模型请求不能显示为实际已发送。
已取消、等待继续、失败、来源过期、固定超限和未知窗口均提供原因与下一步动作。
保留现有聊天右栏功能，不将新管理能力绑定在窄窗会消失的面板中。
离开聊天只结束观察，不停止生成；按会话保存未发送草稿，返回恢复生成状态和输入。
遵循现有 DESIGN.md、复用组件，覆盖所有现有主题、键盘、窄窗、zh/en 和 reduced-motion。
状态反馈与按需展开优先，遵循 Norman 的模型清晰和 Kowalski 的低干扰原则。

## 存量兼容

升级不批量调用模型、不重写历史；下次发送按需初始化，达到阈值才压缩。
升级前非终态轮次保留原协议，终态后下一轮切换；恢复不能偷偷套用新预算或改写原快照。
更换模型重算能力与预算，保留仍有效派生摘要和用户设置，不默认扩大授权或沿用外发同意。

## 验收与风险

| 证据层 | 必须覆盖 |
| --- | --- |
| 针对性自动化 | 整体输入计量、阈值、小窗口、完整轮次及工具配对、冲突优先级、未知模型、错误反馈 |
| 真实 SQLite/Worker | 持久版本、分块激活、取消/重置/排除竞态、重启额度、授权矩阵、读取范围与草稿导航集成 |
| 真实模型 | 至少 30 轮的早期约束、分块覆盖、语义遗漏、历史取回、超限兜底；分别记录摘要与回答成本 |
| 真实 Tauri/WebView2 | 页面往返、草稿保留、持续生成、窄窗/键盘、主题、系统缩放与 reduced-motion |

验收只服务本改动；优先既有测试，新增行为确无覆盖时才补针对性测试。
明确区分替身与真实证据，未完成层次不代勾。近似计数和摘要语义损失是明确剩余风险。
