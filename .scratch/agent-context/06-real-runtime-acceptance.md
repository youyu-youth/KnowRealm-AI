# 06 真实运行验收步骤与记录

当前状态：真实模型指定场景通过，完整验收 PARTIAL（32 轮、五块、取回与规则复验已完成；真实输入超限未触发，完整语义遗漏未逐项审计）；原生桌面 NOT_RUN。2026-10-14 浏览器诊断无活动连接，备用 CDP 仅空白页，没有取得 Tauri/WebView2 的可用控制连接。真实模型使用隔离数据目录、同一供应商和已有有效外发同意，原用户数据与配置未改。

## 准备

1. 在桌面设置导出当前数据作备份；创建专用验收会话，记会话 ID、应用构建/提交、端点和模型（不记录密钥）。确认当前真实模型及外发同意有效。
2. 记录原模型预算配置。可以把应用输入预算暂时调低到 40000 以触发压缩，但不得把实际未知供应商能力填成已知；选择预算能够容纳系统、工具、固定项及当前提问的配置。记录配置来源、回答/摘要输出额度与实际占用。
3. 第一轮发送“本会话所有回答均用中文；每次回答最后一行必须包含验收标记 KR06；项目目标是离线学习工作台；预算约束是三周完成”。在上下文页面把这段约束固定。固定成功后记设置版本和来源身份。

## 真实模型：超过三十轮与分块

1. 连续完成至少 31 次用户提交及模型回答。第 2～30 轮每次使用 `.scratch/agent-context/fixtures/03-long-message.txt` 不同约 600～1000 字片段，加上轮号，要求简短回答；材料只用该公开测试文本。没有实际完成 31 轮时不得把批量插入历史记作此项通过。
2. 第 31 轮要求概括最初目标/约束，核对固定标记与六栏摘要、来源、当前提问、近期往返。记录压缩前后估算占用和供应商真实 usage；分别列回答和摘要请求，缺 usage 写“未知”。记录请求/重试次数、累计摘要额度与耗时；若只能测整轮耗时，单次摘要/回答耗时写“未测”，不要反推。
3. 发送完整长测试文本以触发多块。必须实际观察 `completed_chunks > 1`；未触发记 NOT_TRIGGERED。四次不足时应等待，点击一次继续后额度仅加四次；取消或真实退出进程/重启后核对持久计数、原消息、已完成分块与独立 Run。不把关闭到托盘记为重启。
4. 明确要求模型调用历史查找及读取首轮原文，记录 Tool 名称、来源身份/段/版本与返回片段。模型仅凭摘要回答或没有实际调用时记 NOT_TRIGGERED。
5. 排除首轮、重置、明确纳入首轮（仍应受排除）、恢复排除，再提交后续问题。核对固定暂停/恢复、旧段读取限制及原消息保留。测试来源归档/删除/移出范围时仅使用专用测试资料；恢复后重验版本，不能用缓存正文通过。
6. 实际供应商超限只在受控测试场景执行；若没有发生，记 NOT_TRIGGERED。检查一次有限兜底，不重复 Tool 业务写。故障注入或 HTTP 替身只算自动化证据。
7. 分别评价“完整输入片段覆盖”和“真实语义遗漏”。保留可核对的测试来源，记录摘要漏掉/歪曲的目标、约束、决定、对象及未完成事项；不能用 source_ids 全覆盖证明语义无损。

## 真实 API/SQLite/Worker 与升级/恢复

自动化补充证据见 `06-implementation.md`。原生现场仍需导出专用会话、迁入空数据目录、重启后读取摘要与输出、删除会话后拒绝读取；记导出/恢复身份、源/目标数据目录、迁移版本和各请求结果。旧活跃轮次兼容等待后保留原输入/消费/回执，独立 Run 不应因上下文重置取消。切换端点/模型后核对下一轮预算与同意，原轮拒绝不满足原配置的恢复，不静默换模型。

## 真实 Tauri/WebView2

依次覆盖 LIGHT_DEFAULT、LIGHT_SAGE、DARK_DEFAULT、DARK_INK（当前设置契约的四种主题）。每态记录主题、窗口尺寸、CSS viewport、DPR、原生进程/构建与截图。

1. 未发送草稿 → 上下文页 → 切换另一会话 → 返回：草稿独立且生成持续。摘要等待/继续/取消、REST/事件恢复和错误重试均核对真实持久事实。
2. 鼠标及 Tab/Shift+Tab/Enter/Escape 操作来源、固定、排除、重置及确认卡；关闭弹窗焦点返回触发器，错误不显示成功；按系统减少动效设置检查。
3. Windows 设置分别切到 125% 和 150%，必要时重开应用。在每档窄窗中检查主要动作和局部滚动。实际 200% 放大下重复检查页头、会话选择、返回、正文及设置动作可达；记录使用的是系统缩放还是 WebView 放大。
4. 不把 CSS viewport、deviceScaleFactor、DPR 或根字号 200% 当作 Windows 缩放。发现现有标题栏/页头遮挡也应记 FAIL，不因未改该处记通过。
