# Agent 上下文设计讨论

更新日期：2026-10-12
状态：Q1～Q30 已确认；用户于 2026-10-12 明确调用 to-spec、to-tickets，六票及依赖已批准并发布；未实现。

## 工作约束

- 使用用户指定的 grill-with-docs 流程开展事实核对与分轮访谈。
- 不主动调用 to-spec 或 to-tickets skill；用户于 2026-10-12 分别明确调用两者，按对应授权发布规格及批准后的六票，不自动开始实现。
- 本记录只保存讨论事实和已确认选择，不是规格或实施工单。
- 权威文档变更需先提出具体提案；当前未修改 ADR、GLOSSARY.md 或规范。

## 第一轮已确认

用户答复：按推荐。

- Q1：优先解决长对话遗忘（A）与输入预算、成本及超限（B），同时提供最小的上下文可见性；跨会话延续本期不做（Q4/Q25）。
- Q2：采用 B；系统自动管理，用户可查看、固定材料或关键决定、移除内容、重置上下文。相关能力同时考虑页面操作与自然语言调用。
- Q3：采用 A；允许达到阈值后调用 LLM 压缩旧对话，不每轮执行；保留原始消息与摘要来源。

## 第二轮已确认

用户答复：按推荐。

- Q4：采用 B；覆盖所有现有 Agent 会话，包括自由聊天、资料问答和研究会话，共用预算及历史压缩机制，保持各自材料范围与引用纪律；本期不扩展跨会话记忆。
- Q5：采用 B；按固定栏目总结并保留最近对话，支持按需查回原消息。栏目包括用户目标、明确约束、已确认决定、相关对象及来源、未完成事项、待澄清问题；关联原消息，摘要不能代替执行端授权。
- Q6：采用 B；可信模型元信息自动提供，允许用户覆盖；自定义或无法识别的模型需配置一次。输入预算覆盖系统指令、工具定义、历史、材料和工具结果，预留输出空间与安全余量；计数及超限规则见 Q16/Q27。
- Q7：采用 B；固定、移除、重置从下一轮生效，当前轮沿用固化上下文；需要立即改变时先停止当前轮。调整不隐式取消已提交后台任务，不改变既有授权。

## 第三轮已确认

用户答复：按推荐。

- Q8：采用 B；每次实际调用模型前检查完整请求预算，包括工具往返后的再次调用；达到阈值才压缩。取消固定 10 轮硬窗口，按预算保留最近完整轮次，较早内容进入摘要；工具调用与结果保持配对。具体阈值及余量见 Q12/Q27。
- Q9：采用 B；固定当前会话的明确约束、关键决定、消息或资料片段；固定资料对象代表优先选用，正文仍按预算读取。固定不扩大访问范围、不自动写长期记忆，固定短文本及片段不自动裁掉；无法容纳时明确提示。
- Q10：采用 B；当前会话持续排除指定轮次或资料来源，后续组装、摘要重建、按需检索共同遵守，原数据保留并允许恢复。按可追溯来源过滤，无法承诺自动消除其他消息里没有来源标记的转述；系统规则和执行端权限校验保持有效。
- Q11：采用 A；重置清空历史承接和会话摘要，保留固定项、排除项和材料范围，从当前位置开启新上下文段。旧消息继续可查看，旧段不自动查回，用户明确重新纳入才恢复使用；展示仍生效的固定项、范围和长期记忆，未结束任务真实状态仍可见。

## 第四轮已确认

用户答复：按推荐。

- Q12：采用 B；系统统一管理输入额度，用户主要配置模型能力。可用输入预算考虑输出预留和安全余量，80% 触发压缩、目标降至 60%，作为首版默认值并通过验收校准。固定内容优先，达不到目标但仍在安全预算内可继续，超过预算阻止调用；界面标明估算值。
- Q13：采用 B；覆盖当前上下文段全部待压缩内容，过长分块。以已有摘要加新增待压缩内容增量处理，记录覆盖范围和原消息来源，不跳过早期材料；超长历史可能多次调用，摘要存在语义遗漏风险，关键约束通过固定保留。
- Q14：采用 A；摘要复用当前会话模型与供应商、外发同意及调用日志，不新增第二套模型配置。摘要调用独立检查输入预算、限制输出、记录用量。
- Q15：采用 B；摘要、覆盖范围、固定/排除及重置边界保存到本地 SQLite，属于可重建、带来源和版本的会话状态。轮次绑定实际使用版本，恢复沿用原快照；旧版本计算结果不得覆盖重置/排除后的新状态；不替代学习者长期记忆。

## 第五轮已确认

用户答复：按推荐。

- Q16：瞬时错误自动重试最多 1 次且额度跨恢复累计，配置/同意/额度问题直接反馈。摘要失败保留原摘要与原消息；原上下文能容纳则继续并提示降级，否则停止。主模型实际超限时最多缩减后重试该次模型请求 1 次，不重新执行已提交工具操作，不静默删除固定内容或无限重试。
- Q17：分块成功结果可暂存本地，整批成功且来源/版本有效才激活新摘要。用户取消不自动续跑，原摘要保留；崩溃恢复复用分块须核对版本和来源。迟到结果不得覆盖取消、排除或重置后的状态。
- Q18：采用 B；固定片段绑定来源版本，原文变化标过期，由用户更新/解除；固定对象按当前有效版本选材。来源删除、归档或离开可访问范围后停止使用相关内容，摘要失效或重建；原挂载对象失效沿用拒绝发送。固定条目保留供处理，不能绕过作用域。
- Q19：采用 A；固定/排除/重置作为保留原数据、可恢复的单会话 L1 设置操作复用现有三档授权和回执；默认确认卡，其他档位遵守现有规则。提交处校验对象、版本、执行身份和取消；自动摘要不能修改用户设置或推导授权。
- Q20：采用 B；摘要覆盖对话历史及必要工具结果，系统规则、固定项、独立学习者记忆块和原始资料分别管理，按当前状态组装；摘要不复制这些独立块，原文证据通过来源取回并校验。

## 第六轮已确认

用户通过选择题确认：Q21/Q22/Q24 三项均按推荐；Q23 新建独立页面；Q25 按会话管理；Q26 聊天内入口即可。

- Q21：优先保留必需规则、工具定义、当前提问、固定内容、工具闭环信息，其次是摘要和近期完整轮次，再是材料片段与较早工具细节。小材料预算允许时全文注入，超出则按片段加载并保留定位，不因全文材料挤掉全部对话承接。
- Q22：受限只读取回默认仅限当前会话、当前上下文段，并遵守排除；返回按预算限长且支持继续读取。资料复用领域读取接口，不可重建临时工具输出保留受控快照；关闭卸载到文件却无法取回的框架行为，不开放任意文件访问。读取纳入次数与完整请求预算。
- Q23：新建独立上下文管理页面，替代扩展右栏/窄窗 Sheet 方案；此前会话级作用范围和下一轮生效规则保持。
- Q24：一次自动压缩最多 4 次摘要模型请求，包含重试，恢复不重置。超出保留进度并停止本轮，用户明确继续后才追加额度；未覆盖完整材料不激活新摘要、不跳过剩余内容，摘要与回答用量分别可见。
- Q25：独立页面按会话管理，可切换会话但不混合会话内容，不新增跨会话共享记忆。
- Q26：聊天标题栏带当前会话进入独立页面，提供返回聊天路径；不新增侧栏一级入口。离开页面不取消生成，返回保留未发送草稿。

## 第七轮已确认

用户答复：按推荐。

- Q27：普通回答输出上限默认 4096 Token，摘要默认 1024 Token，允许模型设置调整，小窗口按能力收紧。可靠计数适配预留 10% 安全余量，近似计数预留 20%；区分输入/输出/总窗口，以已知约束计算可用输入预算，缺失需配置。80%/60% 基于可用预算，必需内容放不下则阻止调用；近似计数不保证供应商永不超限。
- Q28：存量会话按需启用；升级不批量调用模型、不重写原消息，下一次发送初始化上下文并按需压缩。升级前已受理轮次沿用原协议，终态后下一轮使用新机制；换模型重新计算预算，保留仍有效的摘要及用户设置。
- Q29：排除优先；冲突固定项保留但暂停注入，恢复来源后重验；重新固定被排除来源需先恢复。重置保留固定/排除，重新纳入旧历史由用户明确选择范围且遵守排除。
- Q30：分别验收自动化与真实 SQLite/Worker、真实模型、真实 Tauri/WebView2。真实模型至少覆盖 30 轮的早期约束、分块摘要、历史取回、超限处理，区分原文覆盖与语义遗漏；真机涵盖页面往返、草稿、不中断生成、窄窗/键盘/主题/系统缩放；未验证项独立列出。

## 当前源码事实

- `backend/app/modules/agent/context.py` 每轮保留最近 10 个完成往返与当前提问，按 60000 字符裁剪最旧往返；目前没有会话摘要接替。
- RECORD 转写在 30000 字符内全文注入，超长改用有效已确认总结、知识点和近三轮引用摘录；LIBRARY_ITEM 正文限长内可注入；COURSE/ALL 主要注入标题清单并按需检索。
- 学习者记忆由 `backend/app/modules/learner/service.py` 确定性聚合并受外发开关和同意控制；不能将会话摘要自动升级为学习者长期记忆。
- `backend/app/modules/agent/middleware/skeleton.py` 同名空件关闭默认 SummarizationMiddleware；此行为对应 ADR-0018。
- 工具调用和部分输出字符已有预算，但不是每次完整模型请求的统一 Token 上限；工具定义和同轮后续往返也需纳入后续设计。
- `backend/app/modules/agent/turns/worker.py` 首次执行固化 system_prompt 与 injected_memories，同轮恢复复用快照及 checkpoint。
- 框架仍可能卸载超大工具结果，而模型可见的 read_file 被隐藏；这是条件性源码风险，尚未实测触发。
- 当前模型设置只有 base_url、api_key、model；SDK 自动 profile 仅按 model_name 查询本地 registry，不验证自定义端点实际窗口。消息 Token 计数入口并不统一支持第三方模型和工具 schema；可复用估算能力但不能宣称任意模型精确计数。
- 已安装框架摘要件可复用触发、计数接缝和工具配对切点，但默认摘要输入会裁剪待总结历史，且未提供产品级跨轮摘要、排除/重置及压缩后完整预算闭环。不能仅启用默认件即宣称满足已确认要求。
- FilesystemMiddleware 公开参数允许关闭对应工具/用户消息卸载，可通过同名中间件替换配置，无需修改 SDK 私有实现。
- 当前写操作授权在 `agent/operations/registry.py` 与 `execution.py` 的受控入口执行；默认档产生提案，用户自然语言明确意图不直接豁免确认。固定/排除/重置尚未注册，可考虑复用现有操作框架；自动摘要维护不能成为业务设置修改或权限依据。
- 当前 `ChatContextPanel.tsx` 右栏显示挂载范围、已注入记忆、授权档、引用和工具信息，没有完整上下文预览、Token 占用、摘要或固定/排除管理；窄于 data 断点（80rem）时整体隐藏，聊天目前没有同功能 Sheet 入口。
- 现有 Dialog、Sheet、Collapsible 与聊天过程投影可复用；真实界面尚未渲染验证。PRODUCT.md 的旧模拟数据描述不能替代当前实现证据；本次不修订无关产品文档。
- `useChatTurns.ts:88-90` 导航卸载只关闭订阅，返回时恢复活动轮次；`ChatConversationView.tsx:101` 未发送草稿仍在组件 useState，独立页面往返保留草稿需要按会话存放草稿，当前不具备该闭环。
