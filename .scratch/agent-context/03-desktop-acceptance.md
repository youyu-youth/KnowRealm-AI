## 验证路径

| 场景 | 生产路径 | 自动化证据与替身边界 |
| --- | --- | --- |
| 历史取回 | 桌面提交 → 原消息/摘要持久化 → search_context/read_context → 后续模型输入及来源页 | `test_compacted_source_is_read_through_real_framework_tool`；模型替身，实际 API/SQLite/Worker/装配 |
| 大网页输出 | web_search → 原裁剪/输出快照 → 持久来源身份 → read_context 或来源页 | `test_real_web_tool_keeps_pre_truncation_text_readable`；仅 Tavily 网络边界替身 |
| 重启读取 | 已持久输出 → 真正退出 → 启动 → 同会话来源 API | `test_output_and_cursor_survive_worker_restart_without_reexecution`；模型替身，实际恢复 |

## 结果范围

人工页面操作可验证实际体验及业务路径；严格次数、完整输入预算、取消竞态和重启幂等继续引用相应自动化/API 证据，不能靠模型自行回答证明。没有读取结果时如实记录错误码与实际 Tool 过程；旧记录未保存正文时无法取回，不编造。

04/05 的固定、排除和重置不在本票范围；跨段隔离的程序证据由现有测试提供，不能因本票没有重置按钮代勾真实跨段验收。真实网络与模型会有实际用量，按现有配置及同意机制执行。
