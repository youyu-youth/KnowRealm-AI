# 会话上下文 ADR 与术语增补提案

状态：2026-10-14 用户已批准，按本文落盘 [ADR-0028](../../docs/adr/0028-durable-conversation-context-and-request-budget.md)、ADR-0018 阶段性关联及 GLOSSARY 四项。本文保留已批准提案范围，生效定义以权威文档为准。

## 拟新增 ADR：0028 持久会话上下文与完整请求准入

Status: accepted（2026-10-14）

### 背景

ADR-0018 在空骨架迁移阶段禁用了默认 SummarizationMiddleware，并保持当时轮初裁剪语义。当前上下文管理需要保留长历史、固定约束、可追溯来源及取消/恢复事实；框架运行态摘要不足以承载这些产品事实。

### 决定

1. 保留 `create_deep_agent` 主骨架、统一模型工厂、公开 Middleware 接缝及内置文件/Shell/子代理工具的既有隔离。默认框架摘要仍不执行；产品持久压缩由最终模型边界 `InputBudgetMiddleware` 调用领域实现。取消固定十轮尾裁，按完整请求预算准入。
2. 端点和模型共同绑定能力。每次回答/摘要调用均计入系统提示、工具定义、协议开销、资料及同轮结果，保留独立输出额度。当前是 UTF-8 近似 Token 计量及 20% 安全余量；不是供应商精确 tokenizer。
3. 原历史不重写。六栏派生摘要保存消息来源、输入身份、段、设置版本、分块结果和实际请求次数。所有原文片段覆盖后才能激活；输入覆盖不承诺语义无损。小窗口预留不足时使用实际累计摘要重分尚未处理片段，原文、已完成分块和消费不归零。
4. 自动压缩最多四次实际摘要请求，瞬时重试和格式降级均计次。继续仅由用户明确追加四次；主模型超限只允许该逻辑请求一次缩减重试，业务工具和原消费不重放。
5. 会话设置、轮次原输入快照、模型请求与业务执行分别保存。页面变更只对下一轮生效；提交时重验 claim、取消、来源及输入身份。旧快照不能覆盖新会话的有效摘要。
6. 固定项、排除项、重置与明确旧历史纳入均属当前会话设置；Agent 与页面共用领域 Service、版本检查和回执。Agent 修改复用 L1 三档及确认机制；摘要不能表达执行授权。排除优先于固定和旧历史纳入。
7. 取回限定会话、段、来源版本及作用域，保留限长与游标。不可重建工具结果持久保存在业务 SQLite；可重建资料优先从领域服务读取。软删除后接口拒绝访问，必要的恢复/取回数据不因轮次终态提前清理。
8. 升级仅作结构迁移，旧会话按需初始化，不批量出网或重写消息；不兼容旧在途图沿既有等待/停止后新问流程，原执行、消费、回执和独立 Run 不改写。
9. 保持 ADR-0025 的业务长期记忆、外发开关与同意边界，以及 ADR-0026 的授权、确认、提交身份和幂等约束。上下文摘要不写学习者长期记忆，页面上下文、来源文本和模型判断均不构成授权。

### 与 ADR-0018 的阶段性差异

仅替代其“默认摘要禁用后无产品压缩”与“轮初固定尾裁”的阶段性行为。默认摘要继续禁用，主骨架、system_prompt 注入、业务事实与 checkpoint 分离及内置工具隔离继续有效。ADR-0018 原迁移记录保留为历史决策，不把当时状态改写成现在已实现。

### 代价与验证

摘要会增加独立计费请求、延迟和语义遗漏风险；近似计量仍可能遇到供应商真实超限。来源过滤不能消除其他消息中无来源标记的转述。自动化与供应商/桌面真实验收分别记录；完整交付需满足 06 工单，不能以模型替身或浏览器缩放模拟关闭真实项。

## 拟增补 GLOSSARY 四项

| 中文 / 英文 | 定义与边界 |
| --- | --- |
| 会话摘要 / Conversation Summary | 当前会话段内及明确纳入该段历史的六栏派生产物，带覆盖来源、版本和持久消费记录。是上下文承接材料，不是原文、资料引用、学习者长期记忆或执行授权；完整分块成功并通过有效性检查后激活。 |
| 上下文段 / Context Segment | 同一会话中自动承接历史的边界。重置开启新段而保留原消息、固定/排除设置与独立 Run；旧段历史不自动注入或取回，明确纳入的范围仍受排除和权限校验。 |
| 固定项 / Context Pin | 当前会话中应优先保留的短文本、明确约束/决定、带版本消息/资料片段或优先取材对象。有效文本不自动裁去；预算不足阻止请求，来源失效或排除时暂停，不扩大资料权限或业务授权。 |
| 排除项 / Context Exclusion | 当前会话按明确轮次或资料身份保存的过滤设置，作用于组装、摘要、检索及取回，优先于固定和旧历史纳入。原数据保留且可恢复；不排除系统规则/授权检查，不保证清除无来源转述。 |

## 批准后的落盘范围

- 新建上述 ADR，并在 ADR-0018 的当前决策关联处链接阶段性替代记录，保留迁移史实。
- 在 `GLOSSARY.md` 对应上下文术语组增加上述四项及 ADR 链接。
- 不修改编码规范；不因本提案宣称真实模型、Tauri 或系统缩放通过。
