# 03 — 全部学习资产聚合导出与完整出口验收

**What to build:** 让用户从 Record 详情一次导出当前已经生成的全部学习资产，并把前三类单项纵切收束成完整 MVP 出口。聚合文件只包含最新且合格的资产，顺序稳定、缺失项自然省略、读取错误不会制造残缺文件；最终以自动化回归和真实 Tauri Windows 落盘证明整个功能可交付。

**Blocked by:** 02 — 习题 / Todo 单项 Markdown 导出.

**Status:** ready-for-agent

- [ ] Record 详情统一导出菜单增加“导出全部学习资产”；已知没有任何合格资产时禁用，最新读取后才确认全部为空时不打开保存对话框并显示“暂无可导出内容”。
- [ ] 每次聚合导出并行调用 Summary、知识点、习题和 Todo 的既有读 API，不依赖当前 Tab 是否挂载或 TanStack Query cache 是否存在。
- [ ] API 明确表示某类资产尚未生成时省略该章节且不生成空标题；任一请求失败、响应不可解释或序列化失败时整次导出失败，不打开保存对话框。
- [ ] 读取完成后形成不可变快照；保存对话框停留期间发生的确认、采纳、作答、编辑或勾选不进入本次文件。
- [ ] 聚合结果接受各端点在点击后的最新事实，不承诺跨端点属于同一个 SQLite 事务快照；不为严格原子性新增后端聚合接口或数据库事务。
- [ ] 文件一级标题为 Record 展示标题，资产章节固定按 Summary → 知识点 → 习题 → 复习资料 → Todo 排列；MVP 尚未生成复习资料时直接省略，不制造占位章节。
- [ ] 聚合文件完整复用各单项资格、顺序、防剧透、Todo 接管、纯文本转义和本地化规则；不得出现 DRAFT、SUPERSEDED、未确认 Summary 或未作答题答案。
- [ ] 聚合默认文件名为 `{Record展示标题}-学习资产.md`，并复用既有 Windows 清理、UTF-8 无 BOM、LF、系统覆盖确认、取消和写入错误规则。
- [ ] 导出进行中禁用重复触发，避免多个保存对话框；完成、取消或失败后恢复，不阻止用户继续阅读 Record。
- [ ] 保存成功与打开失败继续保持两个独立事实；聚合导出离线可用、不写业务表、不写导出历史、不产生 learning_events。
- [ ] 聚合纯函数测试覆盖固定顺序、缺失资产省略、全部为空、Markdown 区块间距、末尾换行和确定性输出。
- [ ] Record 详情最高接缝测试覆盖全部资产成功、部分资产尚未生成、任一读取失败、重复触发、取消、写入失败、保存成功及打开失败，并回归四类单项导出。
- [ ] OpenAPI 类型检查、桌面类型检查、lint、组件测试、桌面构建以及 Tauri Rust 格式/静态检查/构建全部通过；不把这些门禁描述成真实文件系统验收。
- [ ] 真实 Tauri Windows 验收使用至少包含 Summary、知识点、不同作答状态习题及 TODO/DONE 的 Record，保存到中文路径并核对实际文件字节、章节顺序、防剧透、UTF-8 无 BOM、LF、覆盖、取消和“打开文件”。
- [ ] 最终报告分别陈述纯序列化、Record 详情交互、桌面构建和真实 Windows 落盘证据；不得用 jsdom、MSW、fixture 或构建成功替代真实落盘结论。
- [ ] 未来复习资料或其他学习资产只能由对应功能显式加入资产白名单、序列化规则、聚合顺序与测试；本票不实现 Wave B 复习资料，也不建立自动扫描 Tab 或插件系统。
