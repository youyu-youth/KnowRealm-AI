# 04 — 计划 Tab 与今日待学

**What to build:** 学习计划获得日常执行面。知识空间详情页新增第 8 个计划 Tab：目标卡（标题 / 类型 / 期限 / 每日投入 / 整体进度）＋按阶段分组的计划项列表（日期、时长、状态、来源标记）＋项级内联编辑＋空态引导；今日页升级为双源合并——跨空间的学习计划项（排期日 ≤ 今天且未完成）与现有记录 Todo 并列分组、标注来源、勾选完成直接作用于计划项。

**Blocked by:** 03 — 计划编辑、完成与重生成

**Status:** ready-for-agent

- [ ] 课程详情页新增 plan Tab（现 7 Tab 基础上第 8 个，tab 入 URL）：目标卡＋阶段分组计划项列表＋内联编辑（改日期 / 时长、完成、跳过）＋历史版本切换只读查看
- [ ] 空态引导：无目标时引导"设定学习目标"并提示对话主路径（新建目标主路径＝对话，本 Tab 为手动兜底与日常执行面）
- [ ] 今日页双源合并：跨空间计划项（scheduled_date ≤ 今天且未完成，跨空间目标各自排期并列展示）＋记录 Todo，分组标注来源；勾选完成与计划 Tab 状态一致；计划项完成时间戳进入今日学习时长统计（不进学习证据链）
- [ ] zh / en 文案同步（两边 key 一致，en 缺失会被一致性防线拦截）
- [ ] 前端测试：新端点 MSW mock、计划 Tab 组件与今日页双源组件（jsdom）、tab 路由
- [ ] 门禁全绿：前端 vitest + 后端回归（若今日端点扩展涉及后端则含 pytest / OpenAPI --check）
