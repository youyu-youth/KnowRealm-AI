# 05 — 共享来源引用

**What to build:** 同一份资料被多个知识空间复用而不改变归属、不重复入库。用户把已属于"机器学习"空间的论文引用到"Agent 工程"空间：被引用资料的内容进入新空间的课程问答与检索（引用行标注共享来源）；但新空间对引用资料只读——不能生成总结 / 知识点 / 习题，资产仍只在原空间。资料软删时引用失效提示、30 天回收站恢复则引用自动复活、永久删除后引用清理；归属迁移不影响引用。

**Blocked by:** None — can start immediately（与 01~04 并行）

**Status:** ready-for-agent

- [ ] 迁移落地共享引用表：course_id ＋ library_item_id，(course_id, library_item_id) 唯一、创建时间；条目物理删除时引用级联清理
- [ ] 失效为查询期派生：条目软删即失效（展示"来源已删除"）、恢复即复活，不设失效状态字段；归属迁移不影响引用（测试断言）
- [ ] 领域 Service 与 API：课程嵌套引用端点（列表 / 添加 / 删除）；删除引用不动原资料
- [ ] 检索覆盖：新空间 COURSE 范围问答与检索纳入被引用资料的 Record 内容，引用行标注共享来源
- [ ] 资产只读校验：新空间对引用资料拒绝生成总结 / 知识点 / 习题（新错误码登记 zh / en）；引用不授予改、删、迁移原资料权限
- [ ] Agent 工具：list_shared_refs（只读）、add_shared_ref / remove_shared_ref（写，确认卡＋授权＋审计）
- [ ] 前端：课程详情页呈现本空间引用清单与增删入口（具体位置实施时定）；课程问答引用行标注"共享来源"；被引用资料失效时展示"来源已删除"提示；新空间对引用资料生成资产被拒的错误提示（Alert 内联）——zh / en 文案同步、api-types 重新生成
- [ ] 测试：引用增删查与失效派生语义、课程问答覆盖范围（引用资料可检索、资产生产被拒）、Agent 工具确认行为
- [ ] 门禁全绿：pytest（独立 basetemp）+ ruff + pyright + OpenAPI --check + 前端测试
