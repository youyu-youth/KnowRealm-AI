# 01 — Q6 真实录音捕获 POC

Status: completed

**What to build:** 在现有桌面应用中交付最小但真实的 Windows WebView2 录音纵切，证明 MediaRecorder 独立分片、sidecar staging/会话事实、Tauri 防休眠、崩溃恢复以及 04 自动交接。

**Blocked by:** None

- [x] 新增连续迁移与 sidecar 录音会话 API，覆盖创建、未完成会话查询、幂等顺序分片、暂停/继续、封口和确认放弃。
- [x] 开始前验证默认麦克风、`audio/webm;codecs=opus` 支持和 2× 预估磁盘空间；失败不创建会话。
- [x] POC 每 20 秒通过 `stop()` 生成独立 WebM；暂停立即落片，继续开启新片，三小时自动结束。
- [x] Tauri 在录音期间阻止系统自动休眠，结束、放弃和错误时可靠释放；提供短时隐藏窗口验证入口。
- [x] 顶部录音入口可用；开始前最小对话框，录制时常驻计时控制条，支持暂停、继续、结束。
- [x] 启动发现 `RECORDING/PAUSED` 时提供继续、结束处理和确认放弃；发现 `FINALIZING` 时自动重试 04。
- [x] finalize 成功复用现有 Record 列表/详情并进入 Transcript 处理链；失败保留 staging 并可重试。
- [x] 后端、前端、Rust、OpenAPI 与静态门禁通过；所有测试临时文件在测试后删除。
- [x] 人工完成两组不超过 60 秒的真实 Tauri 验收，并分别记录正常轮换与强杀恢复证据。
- [x] 完成报告明确长录音、长期后台节流和生产 5 分钟分片仍未验证，不以自动化或合成音频冒充。
