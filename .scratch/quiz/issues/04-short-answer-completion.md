# 04 — 简答题作答与完成态

**What to build:** 简答题补全作答闭环：先提交非空作答才能看到参考答案，对照后自评对 / 错——**此刻**才落 QUIZ_ANSWERED 事件；未自评显示待自评、可补评；批内全部作答（简答含自评）后展示完成态与答对计数 X/Y。（契约细节见 `.scratch/quiz/spec.md`）

**Blocked by:** 03 — 客观题作答（选择 / 判断）

**Status:** ready-for-agent

- [ ] 简答作答端点：未提交非空作答前不返回参考答案（API 不可绕过、UI 不展示）；提交非空作答后返回参考答案供对照
- [ ] 自评端点：二态 CORRECT / WRONG 写回行上，此刻才落 QUIZ_ANSWERED 事件（契约同 03 票）
- [ ] 待自评状态可见、可补评；补评后事件落表、批次完成度更新
- [ ] 完成 = 批内全部已作答（简答含自评）；完成态展示 + 答对 X / Y 轻量计数
- [ ] 桌面端：简答文本框（非空校验、字数上限）、提交后参考答案对照、自评对 / 错按钮、待自评标记与补评入口、完成态与计数展示
- [ ] 后端 ASGI 全栈测试与桌面 MSW 测试通过（含未作答不可见参考答案、自评才落事件、补评补事件）
