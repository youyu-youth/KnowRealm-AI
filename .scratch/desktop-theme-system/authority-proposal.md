## GLOSSARY.md 末尾增补

**界面模式（Appearance Mode）**：决定当前使用明亮还是暗黑的外观策略；LIGHT / DARK 为手动选择，SYSTEM 跟随系统。SYSTEM 不拥有主题目录。
_Avoid_: 主题 ID、第三套主题

**界面主题（Appearance Theme）**：属于一种实际界面模式的视觉配色方案，以稳定 ID 登记；明亮与暗黑目录及选择独立，只共享组件和语义变量契约。主题不改变布局、字号或业务状态。
_Avoid_: 界面模式、课程主题、跨模式配色转换

**默认主题（Default Appearance Theme）**：所属模式的现有视觉基线；选择字段缺失或该组 ID 无效时回退到它，读取默认值不写文件。其他主题只能继承本模式的默认基线。
_Avoid_: 重置全部偏好、另一模式的派生主题

**外观启动缓存（Appearance Startup Cache）**：按当前数据目录隔离、包含模式及两组主题的派生缓存；权威事实仍为数据目录的本地偏好文件，缓存不可用不阻断启动。
_Avoid_: 权威配置、云同步、数据库备份
