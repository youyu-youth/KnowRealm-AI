# 10 - Markdown 导出

> Wave: A ｜ PRD: §4.4.2（决策 #15）

## 功能描述 / 目标

学习资产一键导出为本地 `.md` 文件——MVP 唯一的"分享"形态（替代分享卡片，决策 #15），桌面文件系统天然支持，零新表零公开访问面。

## 功能范围

**做**：
- 总结导出：主题 + 摘要 + 分点结构 → `.md`
- 知识点导出：名称 / 详情 / 标签 / 重要度 → `.md` 层级列表
- 复习资料导出：随 16（Wave B）补齐同一导出通道
- 导出目标经系统保存对话框选择（本地文件路径）

**不做**：
- 链接分享、shares 表（#15 明确不做）、PDF / 图片导出、导出格式模板自定义

## 核心业务流程

记录详情 → 对应 tab → 导出按钮 → 保存对话框 → 写入 `.md` → 系统打开提示

## 关键业务规则

- 导出内容 = 已确认版本（未确认的草稿总结可导出但需二次确认，避免误导）
- 文件写入走 Tauri 文件能力（保存对话框），路径由用户显式选择
- 导出不产生 learning_events

## 前置依赖

- 06（总结存在且已确认）
- 07（知识点存在）

## 验收标准（出口线）

- [ ] 导出总结 → 文件内容与界面一致、Markdown 结构正确
- [ ] 导出知识点 → 含层级列表与标签
- [ ] 中文文件名与路径正常（Windows）
