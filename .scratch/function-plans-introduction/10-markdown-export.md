# 10 - 学习资产 Markdown 导出

> Wave: A ｜ PRD: §4.4.2（决策 #15）

## 功能描述 / 目标

把 Record 当前已生成且符合导出条件的学习资产保存为本地 `.md` 文件——MVP 唯一的"分享"形态（替代分享卡片，决策 #15），桌面文件系统天然支持，零新表零公开访问面。

## 功能范围

**做**：
- 两种导出方式：聚合导出当前 Record 全部已生成且符合条件的学习资产；或只导出当前 Tab 对应的内容
- 总结导出：当前已确认 Summary 的主题 + 摘要 + 分点结构 → `.md`
- 知识点导出：当前未删除的 ACTIVE 知识点名称 / 详情 / 标签 / 重要度 → `.md` 分节列表
- 习题导出：当前 ACTIVE 题目及按作答状态可见的信息 → `.md`
- Todo 导出：当前正式清单（ACTIVE AI 项、手工项、已接管 AI 项，含 TODO / DONE）→ `.md` 任务列表
- 复习资料导出：随 16（Wave B）补齐同一导出通道
- 导出目标经系统保存对话框选择（本地文件路径）

**不做**：
- 本 plan / Desktop V1 不做链接分享、shares 表；不做 PDF / 图片导出、导出格式模板自定义

## 核心业务流程

记录详情顶部「导出」菜单 → 选择「导出全部学习资产」或「导出当前 Tab」→ 重新读取最新可导出数据 → 保存对话框 → 写入 `.md` → 页内成功状态 → 用户可选择打开文件

## 关键业务规则

- MVP 可导出资产固定为 Summary、知识点、习题、Todo，以及随 16 接入的复习资料；Transcript 与 Ask AI 不属于本 plan。后续新增学习资产时由对应功能计划显式接入，不自动把新 Tab 纳入导出
- 只导出当前已确认 Summary、当前未删除的 ACTIVE 知识点与 ACTIVE 习题；DRAFT / SUPERSEDED 内容不导出
- 习题严格保持页面的答案可见性：未作答题只含题型 / 题干 / 难度 / 选项；已作答客观题增加用户答案 / 结果 / 正确答案 / 解析；已提交未自评的简答题增加用户答案 / 参考答案 / 解析并标记「待自评」；自评后再显示结果
- Todo 导出当前未删除的 ACTIVE AI 项、手工项和已接管 AI 项，TODO / DONE 均保留并按 `sort_order` 输出；DRAFT / SUPERSEDED 不导出
- 每次触发导出时重新从 sidecar 读取最新可导出数据并形成不可变快照；保存对话框停留期间发生的变化不进入本次文件
- 聚合导出并行读取各资产的最新事实，不承诺跨端点属于同一个 SQLite 事务快照
- 聚合文件按 Summary → 知识点 → 习题 → 复习资料 → Todo 排列；缺少的章节直接省略。各资产内部顺序复用当前 API / UI 顺序，不为导出新增排序字段
- 文件一级标题为 Record 标题；聚合导出以二级标题划分各资产，单 Tab 导出保留同一 Record 标题与对应资产二级标题。不写导出时间、内部 ID、批次 ID、模型版本等界面未展示的元数据
- Summary / 知识点 / 习题 / Todo 字段按 UI 的纯文本语义转义会破坏 Markdown 结构的字符并保留段落换行；不输出原始 HTML。复习资料随 16 接入时保留其 Markdown 与代码块语义
- 「导出当前 Tab」在当前内容不受支持或没有可导出内容时禁用并说明原因
- 「导出全部学习资产」任一必要读取失败时整次失败；只有确认该类资产尚未生成时才省略对应章节，不把读取失败伪装成无内容
- 前端基于既有 sidecar API 响应组装 Markdown；不新增后端导出端点或表
- 前端为每种 MVP 资产提供一个小型纯序列化函数，以固定有序白名单组合聚合导出；不建插件系统，不根据 Tab 名称自动纳入资产。后续功能由对应计划显式接入并补测试
- 文件写入走 Tauri 文件能力（保存对话框），路径由用户显式选择；聚合导出默认名为 `{Record标题}-学习资产.md`，单 Tab 导出默认名为 `{Record标题}-{资产类型}.md`；过滤 Windows 非法字符 / 控制字符 / 末尾点与空格并避开保留名，空标题复用 UI 的「未命名学习记录」
- 保存框限制 `.md` 并在缺少扩展名时补齐；文件内容使用 UTF-8 无 BOM、LF
- 用户取消保存对话框时不写文件、不报错、不显示成功；同名覆盖确认交给系统保存对话框
- Markdown 组装失败与文件写入失败分别显示错误；权限不足、磁盘满等写入失败不得显示成功
- 保存成功后不自动启动外部程序；页内显示成功状态及「打开文件」，打开失败不改变文件已保存的事实
- 导出不产生 learning_events

## 验收标准（出口线）

- [ ] 导出总结 → 文件内容与界面一致、Markdown 结构正确
- [ ] 导出知识点 → 含分节列表、重要度与标签
- [ ] 导出习题 → 只含 ACTIVE 题且顺序与界面一致；未作答不泄露答案 / 解析，已作答及简答待自评信息与界面一致
- [ ] 导出 Todo → ACTIVE AI 项、手工项、已接管 AI 项及 TODO / DONE 顺序与界面一致，DRAFT / SUPERSEDED 不进入文件
- [ ] 「导出全部」只包含触发时最新且符合条件的已有学习资产；没有生成的内容不产生空章节
- [ ] 单 Tab 导出只包含对应内容；该 Tab 没有可导出内容时不可触发
- [ ] Summary / 知识点 / 习题 / Todo 中的 Markdown 结构字符不破坏标题与列表层级，文本内容不丢失
- [ ] 取消保存、同名覆盖、读取失败、权限不足与写入失败均符合规则且无假成功
- [ ] 断网时已存在学习资产仍可导出，且不产生 learning_events
- [ ] 纯序列化测试覆盖各 MVP 资产和聚合顺序；Record 详情组件测试覆盖单项 / 全部、禁用态、取消、读取 / 写入失败、保存成功与打开失败
- [ ] 真实 Tauri Windows 验收中文文件名 / 中文路径、UTF-8 / LF 实际落盘及「打开文件」；jsdom / MSW 不替代该项
