# 01 - 工作台骨架与课程管理

> Wave: A ｜ PRD: §4.2 / §9.1 ｜ UI 合同: `DESIGN.md` ｜ 决策引用: #23 #35 #41 #42 #52 #54 #56

## 功能描述 / 目标

基于已初始化的 Tauri + React 桌面工程，先建立后续页面共同复用的工作台骨架，再在该骨架内完成课程管理。首个真实功能同步带入所需的本地数据与 API 基础，不等待独立 Phase 0，也不以静态页面或模拟数据冒充功能完成。

## 功能范围

**做**：
- 工作台骨架：左栏导航、顶部快速捕获栏、内容路由出口、当前导航状态、全局加载/错误/未找到边界
- 骨架入口：今日与知识空间可进入真实页面；尚未实现的收件箱、AI 对话、资产库、学习画像及捕获动作明确禁用或标示未接入，不提供死按钮或假成功
- 课程最小闭环：真实空态、新建课程、课程列表，本地持久化后重启仍可读取
- 课程完整管理：编辑、软删除、按教育阶段/类型筛选、名称搜索（LIKE 子串匹配，#32）
- 课程详情：Overview + Records 两个内容宿主；本 plan 完成 Overview，Records 的真实列表由 02 挂载
- 热词手动列表：课程设置内维护，≤100 词（#54）
- 按需基础：数据目录、SQLite WAL 与迁移、FastAPI sidecar、OpenAPI 类型链、随机端口 + 启动令牌 + 仅绑 `127.0.0.1`（#35/#56）

**不做**：
- Record 列表/详情与处理状态（02）、捕获功能（03/04/05/11）、AI 产物和 Provider
- Course Brain / Knowledge GPS / Course Chat（P3）、热词自动同步（P2）、课程归档/移动
- 完整首启向导、角色卡、数据目录迁移 UI、`.msi` 打包与安装测试
- 脱离 `DESIGN.md` 另建视觉体系，或提前铺设后续功能的静态假页面

## 实施顺序

1. **01-A 工作台骨架**：先完成稳定外壳、导航、路由、真实空态和全局状态边界；此增量不要求后端业务功能。
2. **01-B 最小课程闭环**：在骨架的知识空间内接通真实新建/列表，连通数据目录、SQLite、localhost API 与类型契约。
3. **01-C 课程完整出口**：补编辑、筛选搜索、详情 Overview/Records 宿主、删除和热词；完成后才可宣称 plan 01 通过。

## 核心业务流程

- 启动 → 工作台骨架 → 今日真实空态或知识空间
- 知识空间 → 真实空列表 → 新建课程 → 列表立即出现 → 重启仍存在
- 列表 → 筛选/搜索 → 课程详情 → Overview；Records 显示由 02 接管的真实内容宿主
- 设置入口 → 编辑课程/热词 → 保存生效；删除 → 确认 → 软删 + 级联策略

## 关键规则

- `DESIGN.md` 是 UI 权威：Continuous Work Surface、224px 侧栏、64px 捕获栏、28px 内容边距、Zero Card Chrome；支持亮/暗色、键盘焦点、无整体横向溢出，并检查 1440×900、1280×800、1099×720
- 只有真实动作/导航呈现交互反馈；不可用入口必须可辨识且不触发业务行为；静态信息不得伪装可点击
- 工作台骨架只承载跨页面稳定结构，不包含课程或后续功能的业务状态；后续 plan 复用内容路由出口，不重复实现外壳
- `learning_context` 必填；SCHOOL 必填 `education_stage`，CAREER/INTEREST 必填 `depth`（#23）；`course_type` 可空
- 热词上限 100 词，超出拒绝；本 plan 只维护，04 的 ASR 才消费
- UI 仅通过 localhost sidecar API 读写；查询恒定过滤 `deleted_at`；软删级联与 30 天物理清理规则以数据模型 v2.2 为准
