# 01 - 课程管理增强

> Wave: A ｜ PRD: §4.2 ｜ 决策引用: #23 #41 #52 #54

## 功能描述 / 目标

补齐课程域（M2）MVP 完整能力。Phase 0-05 已交付新建与列表；本 plan 补编辑、软删级联、筛选搜索、课程详情页与热词维护，使"知识空间"管理达到 MVP 验收形态。

## 功能范围

**做**：
- 课程编辑：名称 / learning_context / education_stage / depth / course_type / 热词
- 课程软删除 + 关联数据级联处理（删除弹窗明示"不可恢复"，#41）
- 查询：按教育阶段 / 类型筛选、名称搜索（LIKE 子串匹配，#32）
- 课程详情页：Overview + Records 两 tab（Records 为记录列表宿主，衔接 02）
- 热词手动列表：课程设置内维护，≤100 词（#54）

**不做**：
- Course Brain / Knowledge GPS / Course Chat（P3 占位）
- 热词自动同步（P2）、课程归档/移动

## 核心业务流程

- 列表 → 筛选/搜索 → 进详情 → Overview（课程信息+记录概览）/ Records（该课程记录列表）
- 设置入口 → 编辑表单 → 保存生效
- 删除 → 确认弹窗 → 软删 + 级联 → 30 天后异步物理清理（#41）

## 关键业务规则

- learning_context 必填；SCHOOL 必填 education_stage（5 枚举），CAREER/INTEREST 必填 depth（#23）；course_type 可空
- 编辑保存最后写入生效（sidecar 单写者无并发冲突，数据模型 v2.0 已删乐观锁列）；前端编辑请求串行化，乱序覆盖 to-spec 处理
- 热词上限 100 词，超出拒绝；本 plan 只维护，消费方为 04（ASR）
- 软删级联策略以数据模型 v2.0 为准（to-spec 时核对关联表处理方式）
- 新建时的角色预选默认场景已由 P0-05 覆盖，不重复

## 前置依赖

- Phase 0-05（首启三步 / 建课 / 列表闭环）

## 验收标准（出口线）

- [ ] 编辑课程各字段保存生效
- [ ] 按教育阶段筛选、名称搜索命中正确
- [ ] 详情页 Overview / Records 可切换，Records 列出该课程学习记录
- [ ] 删除课程走确认弹窗，关联数据处理符合级联策略
- [ ] 热词增删生效且超 100 词被拒绝
