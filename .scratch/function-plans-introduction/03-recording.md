# 03 - 录音捕获

> Wave: A ｜ PRD: §4.3.1 ｜ 决策引用: #30 #31 #44 #49 #51 ｜ **开工门槛：录音链路 POC 必须先行通过**

## 功能描述 / 目标

桌面端录音完整捕获链：从按下录音到分片落盘、合并注册后交棒本地处理队列（无上传环节）。捕获端是 Tauri 原生协同最重的一块（WebView 录制 + 分片落盘数据目录），POC 验证是其开工前提。

## 功能范围

**做**：
- 开始 / 暂停 / 继续 / 结束 + 实时时长显示；异常中断尽量保留已录数据
- 录音前最小对话框：标题可空 + 课程选择器（默认"不选 → 收件箱"，#30）
- WebView2 MediaRecorder 录制 webm/opus，每 5~10 分钟分片落盘数据目录 `cache/staging/`（防中断全损、防后台节流）
- 录音会话与分片清单写 recording_sessions（崩溃恢复用）
- 结束后自动进入本地处理队列（无需手动提交）；合并分片注册 record_files（存档原件路径 `files/{record_id}/`，#49），转码交棒 04
- Tauri 防系统休眠；启动时 isTypeSupported 探测，不支持时降级提示
- 磁盘剩余空间防呆：开始前校验 ≥2× 预估体积，不足提示（#44）
- 时长上限 3 小时
- 存档原件 = 合并转码后的 ogg-opus（files/）；webm 分片为中间产物，转码成功即删（cache/，#51）

**不做**：
- 转码 / ASR（04）、录音中标记 ⭐❓📝（P2 课堂标记）、macOS 适配

## 核心业务流程

录音对话框（可空标题+选课）→ 录制（分片落盘 cache/staging + 会话登记 + 防休眠）→ 停止 → 自动进本地处理队列 → 合并注册 record_files → 交棒 04（转码 + ASR；未选课录音 ASR 照常，完成后停 SUMMARY_PENDING）

## 关键业务规则

- 分片 5~10 分钟；单次会话 ≤3h
- 未选课录音照常转码与转写（转写是事实记录，与课程无关，#30）
- 崩溃 / 断电后重启，已落盘分片经 recording_sessions 清单可恢复继续处理
- 分片落盘经 Tauri 壳文件能力；业务数据写经 sidecar API（单写者边界，#35）

## 前置依赖

- 02（录音入口挂快速捕获条；创建的 Record 在列表可见）
- **录音 POC 通过**（WebView2 节流 / 分片 / 异常退出恢复 / 本地 ffmpeg 转码实测，§11-Q6）

## 验收标准（出口线）

- [ ] 录 10 分钟 → 分片落盘 → 合并注册 record_files → 列表状态推进可见（转码由 04 接续）
- [ ] 暂停 / 继续可用，时长显示正确
- [ ] 强杀进程后重启，已录分片可恢复继续处理
- [ ] 转码成功后 webm 分片被清理，存档原件为 ogg-opus（files/）
