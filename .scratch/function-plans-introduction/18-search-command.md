# 18 - 全局搜索与命令面板

> Wave: B ｜ PRD: §9.1（资产库 / 命令面板）｜ 决策引用: #32

## 功能描述 / 目标

跨课程的资产检索与全局动作入口：Ctrl+K 命令面板 + 资产库 FTS5 全文搜索（jieba 应用层分词，#32/ADR-0016）——工作台形态达成的标志性能力。

## 功能范围

**做**：
- Ctrl+K 命令面板：命令项（开始录音 / 新速记 / 新粘贴）+ 搜索一切资产 + 跳转课程与记录
- 资产库视图（左栏入口）：跨课程统一检索学习记录与知识点，MVP = FTS5 全文检索（jieba 应用层分词 + BM25，#32/ADR-0016）
- 键盘交互：Esc 关闭、方向键移动、Enter 确认（cmdk-base 内核行为）
- 搜索结果点击跳转对应详情（记录 / 知识点所在记录）

**不做**：
- 向量语义检索（P2 接管，sqlite-vec）、LIKE 子串兜底、搜索历史 / 收藏

## 核心业务流程

Ctrl+K → 输入关键词 → 混合结果（命令 / 课程 / 记录 / 知识点）→ 方向键选择 → Enter 跳转或执行；资产库视图 → 搜索 → 结果列表 → 点开详情

## 关键业务规则

- MVP 搜索 = SQLite FTS5 + jieba 应用层分词（统一索引表、BM25 排序，ADR-0016；2026-09-07 终裁跳过 LIKE 阶段，#32 已随 PRD v2.6 改写）
- 搜索范围恒带 deleted_at 软删过滤（单用户库无 user_id），归档课程及其资产不进结果
- 搜索对象：记录标题与转写文本、知识点名称与详情（tags 入 keywords 列）、课程名称（hot_words 入 keywords 列）——已 to-spec 细化（`.scratch/search-command/spec.md`）
