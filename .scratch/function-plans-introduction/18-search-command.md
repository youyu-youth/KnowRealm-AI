# 18 - 全局搜索与命令面板

> Wave: B ｜ PRD: §9.1（资产库 / 命令面板）｜ 决策引用: #32

## 功能描述 / 目标

跨课程的资产检索与全局动作入口：Ctrl+K 命令面板 + 资产库 LIKE 全文搜索（MVP 子串匹配，#32）——工作台形态达成的标志性能力。

## 功能范围

**做**：
- Ctrl+K 命令面板：命令项（开始录音 / 新速记 / 新粘贴）+ 搜索一切资产 + 跳转课程与记录
- 资产库视图（左栏入口）：跨课程统一检索学习记录与知识点，MVP = LIKE 子串匹配（#32）
- 键盘交互：Esc 关闭、方向键移动、Enter 确认（Radix 原生行为）
- 搜索结果点击跳转对应详情（记录 / 知识点所在记录）

**不做**：
- 向量语义检索（P2 接管）、中文分词扩展（明确不引入，#32）、搜索历史 / 收藏

## 核心业务流程

Ctrl+K → 输入关键词 → 混合结果（命令 / 课程 / 记录 / 知识点）→ 方向键选择 → Enter 跳转或执行；资产库视图 → 搜索 → 结果列表 → 点开详情

## 关键业务规则

- MVP 搜索 = SQLite LIKE 子串匹配，符合中文直觉，不引入中文分词（#32）
- 搜索范围恒带 deleted_at 软删过滤（单用户库无 user_id）
- 搜索对象：记录标题与转写文本、知识点名称与详情、课程名称（范围 to-spec 细化）
