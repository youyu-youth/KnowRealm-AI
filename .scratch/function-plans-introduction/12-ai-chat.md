# 12 - AI 对话（自由 + @记录）

> Wave: A ｜ PRD: §4.5 ｜ 决策引用: #38 #39 #40 #41 #52 #53（红线 #5 #11）｜ 2026-08-28 grill 定案回写

## 功能描述 / 目标

💬 AI 对话一级入口（ChatGPT 式）：对话列表 + SSE 流式。Wave A 交付自由聊天与 @记录挂载（Record Chat）两种模式；@课程 / @全部资料 / 联网搜索按阶段后补。

## 功能范围

**做**：
- 路由 `/chat`（对话列表 + 空态引导卡 #42）与 `/chat/$sessionId`（内容区左列对话列表 + 右侧对话区）；复用 01 左栏入口与 02 记录查询/详情跳转；模式（自由 / @选记录）新建时一次选定，会话内不可换、不可中途挂载；列表按 `updated_at` 倒序，重命名/删除走列表项菜单，删除弹窗明示"不可恢复"（#41 软删、30 天物理清理）
- UI 文案一律用"对话"，禁止裸用"会话"（CONTEXT.md 词条：聊天会话 / 自由聊天 / 挂载 / 知识点解释）
- 最小档案切片：迁移建 `profile` 表（按数据模型 v2.2 全列建齐，含昵称/头像）；`GET/PATCH /api/profile` 与设置页"档案"区块只暴露 `primary_role + about_me`，昵称/头像编辑留 14
- 自由聊天：会话创建时把用户角色 + 自我介绍**快照为一条 SYSTEM 消息落库**（#52；档案未建时中性默认）——"新会话生效不追溯"由快照天然成立；不建向量索引、不进 Learning Evidence（红线 #5）
- @记录挂载（Record Chat）：基于当前记录多轮对话；@选择器可选 = **存在 Transcript 的记录**（含 Inbox 未归类，不要求总结已确认），无转写（NOTE/处理中）置灰说明
- 上下文组装（#39）：字符预算 `CHAT_CONTEXT_CHAR_BUDGET=60000`（部署级 .env）；两级裁剪——① 超预算从最旧对话轮开始丢（转写仍常驻）；② 转写超 3 万字不再常驻全文，替换为已确认摘要 + 知识点全文 + 近 3 轮被引用的转写摘录段；**1 轮 = 一条成功完成的 user→assistant 往返**（中断轮不计）；上下文每轮取记录**当前最新转写版本**（不钉死 source_version）
- 答案引用：模型正文 `[1][2]` 角标 + 文末固定格式引用块（每条摘录 ≤80 字）；后端流结束解析 → `citations_json` 并从展示正文剥离；**子串校验**——摘录必须在当前转写中真实存在，否则丢弃该条（防幻觉引用）；点击跳 `/records/$id?tab=transcript` 文本搜索定位 + 高亮，找不到提示"原文已变动"；自由聊天不产出引用
- 知识点解释（M5 简化版）：从 07 知识点进入 = **ASK 模式 + 挂载该 KP 所属 Record + 系统提示注入 KP 快照**，不加列不加 mode（CONTEXT.md：知识点解释）；输入框预填建议问题（如"给我讲讲〈KP 名〉"），用户直接发送或改写
- SSE 流式：六类事件 token / status / citation / interrupt / done / error；**请求受理即发首条 status 事件**（结构保证首事件 ≤3s）；`interrupt` 类型保留在协议中但本 plan 不产生（P5 Tutor）
- 中断与并发：客户端断连 → sidecar 取消生成，半截 assistant 内容**不落库**；会话末尾存在"无回复 user 消息"时，下一次发送视为**补答**（复用该 user 行，不重复落库）；同会话同时只允许一条在途，第二条 409，前端流式期间禁用发送
- 挂载记录被删除 → 会话保留可读 + "原记录已删除"失效态（#40），输入区禁用、仅可浏览
- 形态预留（#53）：LangGraph `create_agent` agent 循环，Wave A 工具集为空（"检索第一工具"坑位 P2 填）；**每轮从 `chat_messages` 重建消息列表**喂给 agent（上下文裁剪显式可控），AsyncSqliteSaver + `thread_id=chat-{session_id}`，checkpoint 只承载当轮运行态、不做跨轮记忆
- 无 Provider（#38）：左栏入口保持可见可进，进入后"未配置 AI 服务"空态 + 就地配置（复用 06 ProviderConfiguration 模式），配完即用；发送前再校验
- 迁移 0014：`chat_sessions`（软删）+ `chat_messages`（追加型）+ `profile`

**不做**：
- @课程（P3）、@全部资料（P2）、web_search（P2）、对话转学习资产（P2）、Tutor / Teach-back 模式（P5）
- 昵称/头像编辑、多供应商卡管理（留 14）
- Segment / Source Anchor 完整溯源（P2；本 plan 引用仅为转写文本定位）

## 核心业务流程

新建对话 → 选模式（自由 / @选一条记录）→ 提问 → 受理即回 status → SSE 流式输出（token 逐字渲染）→ 引用可点击定位 → 多轮追问（近 10 轮记忆，超预算裁剪）

## 关键业务规则

- **自由聊天不建向量索引、不进 Learning Evidence 链**（红线 #5：闲聊不产生证据）；聊天域不写 learning_events
- 挂载会话不叠加角色注入（#52）；SYSTEM 快照创建时定，角色改动不追溯
- Summary / Tutor / TeachBack 禁止联网工具（红线 #11）；本 plan 工具集为空（P2 起 web_search 仅聊天域）
- 客户端断连清理资源；流内异常发 error 事件，不无声断流；半截回复不落库
- 引用摘录必须经后端子串校验，编造引用丢弃
- 对话全文不进日志；`llm_call_logs` 只记元数据（工厂层统一埋点）

## 验收标准（出口线）

- [ ] 自由聊天流式输出，首事件 ≤3s，对话可重命名 / 删除（删除弹窗明示不可恢复）
- [ ] 挂载已处理记录追问细节（如"后面讲的公式"）能答且带可点击引用，引用点击定位到转写位置
- [ ] 超过 10 轮后早期对话被裁剪但回答仍连贯（上下文组装生效）
- [ ] 删除已挂载记录 → 对话仍可读并显示失效标记，输入区禁用
- [ ] 改角色 + 自我介绍后，新建自由聊天语气变化（存量对话不变）——由本 plan 档案切片承载
- [ ] 同会话并发发送第二条返回 409，流式期间前端禁用发送
- [ ] 引用摘录经后端子串校验，编造引用被丢弃不展示
- [ ] 中断后半截回复不落库；重试复用原 user 消息，历史无重复提问
- [ ] 无 Provider 时进入"未配置 AI 服务"空态并可就地配置，配置完成后直接可用
