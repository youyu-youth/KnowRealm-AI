# 12 - AI 对话（自由 + @记录）

> Wave: A ｜ PRD: §4.5 ｜ 决策引用: #39 #40 #52 #53（红线 #5 #11）

## 功能描述 / 目标

💬 AI 对话一级入口（ChatGPT 式）：会话列表 + SSE 流式。Wave A 交付自由聊天与 @记录挂载（Record Chat）两种模式；@课程 / @全部资料 / 联网搜索按阶段后补。

## 功能范围

**做**：
- 左栏一级入口：会话列表（新建 / 历史 / 重命名 / 删除）
- AI 对话入口挂载 01 已提供的左栏与路由出口；@记录选择和跳转复用 02 的 Record 查询与详情
- 自由聊天：系统提示注入用户角色 + 自我介绍（#52；档案未建时中性默认）
- @记录挂载（Record Chat）：基于当前记录多轮对话；MVP 上下文组装（#39）= 转写全文常驻 + 溢出按对话轮数递减（保留摘要 + 知识点 + 近 3 轮引用的转写段）
- SSE 流式：六类事件 token / status / citation / interrupt / done / error；首事件 ≤3s；断连不自动重放
- Chat Memory：近 10 轮
- 答案引用：MVP 为转写段文本定位（点击定位到转写位置；完整 Source Anchor 溯源 P2）
- 知识点解释简化版：点击知识点进入针对该知识点的教学式对话（@知识点模式，M5 简化版）
- 挂载记录被删除 → 会话保留可读 + "原记录已删除"失效态（#40）
- 形态预留：LangGraph agent 循环实现，检索为第一工具（单工具行为等同纯管线，#53）

**不做**：
- @课程（P3）、@全部资料（P2）、web_search（P2）、对话转学习资产（P2）、Tutor / Teach-back 模式（P5）

## 核心业务流程

新建会话 → 选模式（自由 / @选一条记录）→ 提问 → SSE 流式输出（token 逐字渲染）→ 引用可点击 → 多轮追问（近 10 轮记忆）

## 关键业务规则

- **自由聊天不建向量索引、不进 Learning Evidence 链**（红线 #5：闲聊不产生证据）
- 挂载会话不叠加角色注入（#52）；角色改动对自由聊天"新会话生效不追溯"
- Summary / Tutor / TeachBack 禁止联网工具（红线 #11）；本 plan 也无联网工具（P2 起 web_search 仅聊天域）
- 客户端断连清理资源；流内异常发 error 事件，不无声断流
- 对话全文不进日志

## 前置依赖

- 01（左栏与路由出口）
- 02（记录选择与详情）
- 05 或 04（@记录挂载至少有一条真实 Transcript 来源，不要求文档与音频同时完成）
- 06（上下文含已确认总结）、07（知识点解释入口）

## 验收标准（出口线）

- [ ] 自由聊天流式输出，首事件 ≤3s，会话可重命名 / 删除
- [ ] 挂载已处理记录追问细节（如"后面讲的公式"）能答且带可点击引用
- [ ] 超过 10 轮后早期对话被裁剪但回答仍连贯（上下文组装生效）
- [ ] 删除已挂载记录 → 会话仍可读并显示失效标记
- [ ] 改角色 + 自我介绍后，新建自由聊天语气变化（存量会话不变）
