# 15 - 模拟测试

> Wave: B ｜ PRD: §4.4.2 模拟测试行 ｜ 决策引用: #20 #33 #43 #46 #51

## 功能描述 / 目标

从题库抽题组卷的测验模式：作答、评分、留痕。核心是简答题 AI 语义评分及其可信度边界——confidence 仅作 UI 复核标记，禁止参与掌握度计算。

## 功能范围

**做**：
- 从该记录（或课程范围题库，to-spec 定）抽题组卷、依次作答、提交
- 客观题规则判分；简答题 AI 语义评分
- 简答评分**最终分值与评分依据必须保存**
- 低置信复核：评分 confidence < 0.7（部署级配置 `SHORT_ANSWER_REVIEW_THRESHOLD`，不进用户 UI，#51）标记"建议人工复核"（#20）
- QUIZ_TEST_COMPLETED 事件落 learning_events（幂等，#43）
- 测验结果页：得分、逐题对错、评分依据展示
- 习题 Groundedness 评测样本建立（随 Wave B，#46）

**不做**：
- 自适应选题（P5，F13）、Transfer Challenge（P5）、错题本自动重练

## 核心业务流程

记录详情 → 模拟测试 → 抽题组卷 → 作答 → 提交 → 客观题即判 + 简答 AI 评分 → 结果页（低置信标记复核）→ 事件落表

## 关键业务规则

- **confidence = LLM 结构化输出自评字段，仅用于 UI 复核标记，禁止参与掌握度计算**（#33）
- 题库来源 = 08 生成的习题；抽题规则（随机 / 覆盖知识点）to-spec 细化
- 评分失败 → 该题标记待复核，不阻塞整卷结果
- 评分 prompt 与输出全文不进日志；埋点记 token / latency / model

- [ ] 测验中断后重进不产生重复事件
