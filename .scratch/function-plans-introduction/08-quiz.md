# 08 - 习题生成与作答

> Wave: A ｜ PRD: §4.4.2 ｜ 决策引用: #43（Q10 形态定稿）

## 功能描述 / 目标

总结确认后按需生成习题，并以**逐题模式**作答：客观题自动判分、简答题对照参考答案自评。组卷测验与 AI 语义评分留给 15（Wave B）。

## 功能范围

**做**：
- 题型多选（选择题 / 判断题 / 简答题）→ AI 建议数量 3 / 5 / 10 道 → 生成
- 必含字段：题干 / 选项 / 答案 / 解析（简答题为参考答案），结构化 Schema 校验
- 逐题作答：客观题（选择 / 判断）提交即自动判分；简答题显示参考答案、用户自评对错（Q10 定稿）
- QUIZ_ANSWERED 事件落 learning_events（两种题型都落，幂等键，#43）
- 重新生成：基于反馈重新生成，不限次
- 习题列表与作答 UI 挂记录详情 tab

**不做**：
- 组卷 / 测验模式 / AI 语义评分 / 低置信复核标记（15，Wave B）、错题本

## 核心业务流程

总结已确认 → 选题型与数量 → 生成 → 逐题作答（客观题判分 / 简答自评）→ 事件落表 → 完成状态展示

## 关键业务规则

- 触发前提 = 总结已确认
- 作答历史是 MVP 唯二业务事件来源之一（与 06/07 并列四事件，#33/#43）——幂等键规则同步生效
- 题目结构化输出必经 Schema 校验；本 plan 不引入 confidence 字段（评分域在 15）
- 输出全文不进日志

- [ ] QUIZ_ANSWERED 事件逐题落表且幂等
- [ ] 重新生成一次可用新题替换
