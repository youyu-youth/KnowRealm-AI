# 20 - 习题 Groundedness 评测样本

> Wave: B ｜ PRD: §8.4 测试策略 ｜ 决策引用: #46 ｜ 2026-08-31 从 15-mock-test 拆出；2026-09-09 grill 定稿实施决策

## 功能描述 / 目标

为 08 习题生成建立忠实度（Groundedness）评测样本：验证生成的习题是否忠于生成来源，防止无中生有。它评测的是**习题生成质量**，与模拟测试功能（15）正交。

## 实施决策（2026-09-09 grill 共识）

### 评分锚点

groundedness = 习题（题干/选项/答案/解析）可由**已确认总结**推出的程度——生成输入只有已确认总结与课程上下文，不含转写全文。转写摘录仅作样本参考附件，不评分；发现"总结幻觉传导到习题"时标注「非习题生成缺陷，转总结域（06 黄金样本）」。

### 交付物与落点

`docs/evaluation/`（新建目录）下两份 markdown：
- `quiz-groundedness-samples.md` —— 样本集 + 回归评审记录表 + 脱敏规则说明
- `quiz-groundedness-checklist.md` —— 人工评审 checklist（独立成文，回归评审直接引用）

### 样本结构与规模

1 条 = 1 道题完整配对（来源材料 + 该题全文 + 人工标注），同一来源材料样本间复用。10 条起步：五种题型（单选/多选/判断/填空/简答）各 ≥1 道，来自 ≥2 个不同来源（不同课堂/学科）。

每条必记元数据：`model`、`prompt_version`（当前 `quiz_v1`）、采集日期、题型、难度、脱敏来源代号（`SRC-A` 式）。不记 provider/latency/token。

### checklist 打分制

四维（题干可从来源推出 / 答案正确 / 选项合理 / 无幻觉）+ 总判定三级制 **PASS / PARTIAL / FAIL**（部分幻觉是高频真实场景，二值丢信息）。每条标注必填**证据引用**（总结中支撑该题的要点编号）。题型不适用维度标 N/A，附逐题型适配表（判断题选项固定「对/错」不评选项合理性；简答/填空无选项）。

### 如实快照

FAIL / PARTIAL 样本原样保留——回归基线与 prompt 改进前后对比的证据，不精选全 PASS。

### 回归评审流程

触发条件 = prompt_version 变更或更换模型；用 checklist 对全部样本重标一轮；结果记入样本集文档末尾「回归评审记录」表（日期 / model / prompt_version / PASS·PARTIAL·FAIL 计数 / 一句话结论）。不做自动对比、不做 CI。

### 隐私脱敏

agent 整理初稿时将课程名/人名/机构替换为「课程A」类占位符（不动学科内容），用户复核；规则写入样本集文档头部，后续补样本沿用。

### 分工与采集清单

用户从真机 UI 采集 → agent 整理样本初稿 → 用户人工填写四维判定与证据引用（agent 不代标，与「真机验收由用户执行」惯例一致）。

每来源采集一份材料（样本间复用）：
1. 完整已确认总结（主题 + 摘要 + 全部 sections）——评分锚须为模型完整输入，摘录会失真
2. 转写代表性摘录一份（参考附件）
3. 该来源当前 ACTIVE 习题全文（题干/选项/答案/解析/难度）
4. model 名（设置页）+ 采集日期

### 范围边界

本工单只管习题域；目录结构与 checklist 风格前瞻兼容总结黄金样本（06 遗留验收项，是否落地另议）。GLOSSARY.md 已补「忠实度（Groundedness）」词条。

## 功能范围

**做**：
- 黄金样本集 `docs/evaluation/quiz-groundedness-samples.md`（结构见实施决策）
- 人工评审 checklist `docs/evaluation/quiz-groundedness-checklist.md`
- 回归评审记录表（随样本集文档落地）

**不做**：
- 自动化评测脚本、CI 集成、自动对比
- 其他评测维度（引用准确性 / Concept 抽取精度 / 简答评分一致性 / 误报率 / 推荐接受率——随对应阶段补建，#46）
- 总结黄金样本（06 域）
