# 17 - 学习统计

> Wave: B ｜ PRD: §4.1 学习统计行 ｜ 决策引用: #54

## 功能描述 / 目标

个人学习数据的聚合展示：全部由业务表聚合计算，不建独立事实表；入口为"今日"页底部统计卡片区（不新增左栏项，#54）。

## 功能范围

**做**：
- 统计指标：累计学习时长 / 记录数 / 课程数 / AI 总结次数 / 习题生成与完成次数 / 问答轮次
- 今日页底部统计卡片区（#54 入口形态）
- 由业务表聚合（records / courses / ai_summaries / quizzes / chat_messages 等）

**不做**：
- 趋势图表（Wave B 出口线之外，后续可加）、按周 / 月维度报表、token 用量（归 19 服务与用量分区）

## 核心业务流程

今日页 → 底部统计卡片区 → 各卡片展示聚合数字（进入应用即见，无需主动刷新）

## 关键业务规则

- **口径定稿（#54）**：AI 总结次数 = ai_summaries 行数（生成次数，含重新生成版本）
- 学习时长口径：录音 / 导入音频时长聚合（to-spec 核对可计算来源）
- 全部聚合查询带 deleted_at 软删过滤（单用户库无 user_id）；不建独立统计事实表（由现有业务表算出）
- 统计查询不拖慢今日页（聚合代价可接受，必要时缓存）

## 前置依赖

- Wave A 功能集（06 / 07 / 08 / 12 等产生数据的来源表就绪）

## 验收标准（出口线）

- [ ] 今日页底部显示统计卡片区
- [ ] 各项数字与业务表实数一致（含"AI 总结次数 = ai_summaries 行数"口径）
- [ ] 重新生成总结后，AI 总结次数 +1
