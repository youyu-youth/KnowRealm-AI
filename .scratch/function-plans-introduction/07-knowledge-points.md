# 07 - 知识点提取

> Wave: A ｜ PRD: §4.4.2 ｜ 决策引用: #43（红线 #9）

## 功能描述 / 目标

总结确认后按需触发的第一项后续 AI 能力：从转写 + 总结中提取知识点（KP），经用户筛选编辑后确认保存为 Record 级学习资产。

## 功能范围

**做**：
- 总结确认后按需触发（记录详情 → 知识点 tab）
- 结构化输出：名称 / 详情 / 标签 / 重要度 / 来源锚点（Pydantic Schema 校验）
- HITL：用户删除 / 编辑 / 补充后确认保存
- KNOWLEDGE_CONFIRMED 事件落 learning_events（幂等键，#43）
- 重新生成：基于反馈或编辑后转写重新生成，不限次
- 知识点列表渲染于记录详情 tab（挂 02 壳）

**不做**：
- 知识点解释对话入口（归 12，@知识点模式）、Concept 抽取与对齐（P3）、跨记录 KP 汇总视图

## 核心业务流程

总结已确认 → 生成知识点 → 用户筛选（删 / 改 / 补）→ 确认保存 → 事件落表 → 知识点 tab 展示

## 关键业务规则

- **KP 是 Record 级资产，≠ Concept（Course 级）**——不得混同或互并（红线 #9）
- 触发前提 = 总结已确认（未确认不解锁）
- 结构化字段必经 Schema 校验后入库；来源锚点指向转写位置（P2 起完整）
- 输出全文不进日志
