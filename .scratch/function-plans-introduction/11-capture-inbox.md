# 11 - 轻捕获与收件箱

> Wave: A（Wave B 增段：整理增强）｜ PRD: §4.3.0 / §6.6 ｜ 决策引用: #29 #30 #51

## 功能描述 / 目标

五级捕获的轻端（L1 速记 / L2 粘贴）与收件箱（Inbox）最小闭环：先捕获后整理——未归类内容纯存储不耗 token，归类 / 升级 / 删除三动作事后处理。

## 功能范围

**做（Wave A）**：
- ⚡速记：全局快捷键（默认 Ctrl+Alt+N，#51）弹出输入框，一句话~几段，存 Inbox（NOTE 态）；依赖关窗驻留托盘常驻（行为默认值在 13，本 plan 消费）
- 📋粘贴长文本：粘贴框；**未选课 = 仅存储 NOTE（等同速记）；已选课 = 直接进总结管线**（#29）
- Inbox 视图：course_id 为空的学习记录时间流（左栏入口）
- 三动作：**归类**（填 course_id，不触发 AI）/ **升级**（强制先归类 → 触发 06 总结管线）/ **删除**
- 未选课录音（03/04 停于 SUMMARY_PENDING 的记录）在此归类 + 升级进同一闭环（#30）
- 速记 / 粘贴入口挂载 01 已提供的顶部快速捕获栏；Record 实体、列表与详情复用 02

**做（Wave B 增段）**：
- Inbox 整理增强：批量归类 / 按类型筛选

**不做**：
- 网页剪藏 L3（P2）、速记直接生成知识点、自动归类建议

## 核心业务流程

快捷键 → 速记框 → 存 Inbox（NOTE）→ 事后整理：归类（纯归档）/ 升级（归类后触发总结 HITL）/ 删除；已选课粘贴跳过 Inbox 直接进管线

## 关键业务规则

- **未归类内容不自动消费 token**（#29）：NOTE 态纯存储
- **升级必须先归类课程**（#29）：learning_context / education_stage / depth 是总结 AI 上下文硬依赖，无课程不总结
- 归类不触发管线，升级才触发（#29）
- 速记纯存储，无任何 AI 调用

## 前置依赖

- 01（Inbox 视图挂载既有左栏与路由出口）
- 02（记录实体、列表与详情复用）
- 06（升级触发的总结管线）

## 验收标准（出口线）

- [ ] 任意界面快捷键唤起速记 → 保存 → Inbox 时间流出现（NOTE 态）
- [ ] 未选课粘贴 → NOTE 纯存储，无 AI 调用发生；已选课粘贴 → 直接进总结
- [ ] Inbox 中先归类再升级 → 进入总结 HITL 闭环走通
- [ ] 未选课录音转写完成后，归类 + 升级解锁总结（#30 闭环）
- [ ] （Wave B）批量归类多条生效
