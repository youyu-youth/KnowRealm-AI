# 13 - 偏好设置

> Wave: B ｜ PRD: §4.1 偏好设置行 ｜ 决策引用: #51（v2.0 单一本地配置）

## 功能描述 / 目标

单一本地配置 `config/settings.json` 的落地：偏好 + 本机行为合一读写（v2.0 合并原 user_settings / local_settings，无漫游概念）。

## 功能范围

**做（全部写 config/settings.json，即时生效）**：
- 深色模式：LIGHT / DARK / SYSTEM——切换 = 改 theme + 挂 / 摘 `<html>` 的 `.dark` class
- 字体大小
- 时区：默认取 OS、可覆盖（复习提醒 P4 才生效，先存后用）
- locale：V1 仅中文，设置页隐藏语言项（#51）
- 关闭窗口行为（默认驻留托盘，#51——速记快捷键依赖常驻）
- 开机自启（默认关）
- 速记快捷键自定义（默认 Ctrl+Alt+N 可改，供 11 消费）
- UI 记忆：上次学习场景、习题数量、窗口记忆

**不做**：
- 语言切换（V1 隐藏）、"数据与隐私"页（P2 细化）

## 核心业务流程

设置页（偏好分区）→ 改任一项 → 写 config/settings.json → 即时生效，重启后保持

## 关键业务规则

- 全部偏好仅存 config/settings.json，不落第三处状态（#51）；换机随全量导出包迁移（14）
- 深色模式全应用跟随（含图表与代码高亮双主题）

## 前置依赖

- P0-05（设置页框架）
- 11（快捷键自定义的消费方存在）

## 验收标准（出口线）

- [ ] 修改速记快捷键后新键生效（旧键失效）

- [ ] 偏好改动全部持久化于 config/settings.json（重启不丢）
