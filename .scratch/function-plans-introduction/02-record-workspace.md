# 02 - 记录列表与详情

> Wave: A ｜ PRD: §4.3.4 / §9.1 / §6.5 ｜ 决策引用: #7 #40 #41 #42 #54

## 功能描述 / 目标

学习记录（Record）的浏览宿主与工作台骨架：八态业务态的用户可理解展示、记录详情壳、删除链，以及左栏导航 / 顶部快速捕获条 / 今日页最小版。后续功能 plan 的产出均挂载到本壳上。

## 功能范围

**做**：
- 工作台骨架：左栏导航（今日 / 收件箱 / 知识空间 / AI 对话 / 资产库入口就位，后两者随 12/18 激活）+ 顶部快速捕获条（按钮随 03/04/05/11 挂载）
- 今日页最小版：待确认总结（HITL 待办）列表入口（随 06 生效）
- 课程详情 Records tab：记录列表（时间倒序、状态徽章）
- 记录详情壳：tab 框架（总结默认 / 转写 / 知识点 / 习题 / 复习 / Todo / Ask AI），各 tab 内容由后续 plan 挂载，本 plan 只建壳与空态引导卡（#42）
- 八态状态展示 + FAILED 重试入口
- 删除链：软删弹窗明示不可恢复（#41）→ 数据目录文件 / 向量异步物理清理 → 挂载对话不级联删除（#40）→ 处理中删除竞态（worker 每步写前校验 deleted_at，#54）
- 状态刷新：本 plan 用轮询兜底；sidecar SSE 事件订阅由 04 引入（首个真实信号源）

**不做**：
- 转写 / AI 产物内容渲染（后续 plan）、收件箱视图（11）、已删恢复 UI（V1 无）

## 核心业务流程

- 课程详情 → Records → 点记录 → 详情壳（按状态显示可用 tab）
- 删除 → 确认弹窗 → 软删 → 列表消失 → 30 天后异步物理清理
- FAILED 记录 → 重试入口 → 交回对应管线重跑

## 关键业务规则

- record.status 只表达 8 个业务态（NOTE / DRAFT / CONTENT_PROCESSING / SUMMARY_PENDING / SUMMARY_PROCESSING / SUMMARY_READY / COMPLETED / FAILED；UPLOADING 随 #55 消解）；技术任务态一律在 processing_jobs，不混写（#7）
- 软删 30 天后异步物理清理，与文件 / 向量清理同批次（#41）
- 删除不级联挂载的对话：会话保留可读、标记"原记录已删除"失效态（#40，UI 行为随 12 验证）
- 每个查询带 deleted_at 软删过滤（单用户库无 user_id，#28）
