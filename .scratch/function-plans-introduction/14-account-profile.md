# 14 - 档案、供应商与数据目录

> Wave: B ｜ PRD: §4.1（用户档案 / 数据目录管理）/ §6.4 ｜ 决策引用: #52 #55 #11

## 功能描述 / 目标

无账号体系下设置页"档案与供应商"分区的完整闭环：本地档案编辑、供应商卡管理、数据目录管理与全量导出/导入（原 P2 提前 Wave B，#55）。首启三步骨架已由 Phase 0-05 承载，不重复。

## 功能范围

**做**：
- 档案：昵称、头像（数据目录本地文件）、角色 primary_role 四选一 + about_me（≤200 字）——本地 profile 表，随时可改（#52）
- 供应商卡（/api/providers）：DashScope 预设 / 自定义 OpenAI 兼容端点（base_url + key + model）/ 腾讯云 ASR；CRUD + 连接测试；密钥存 config/providers.json（明文，#11）
- 数据目录管理：打开数据目录 / 更改数据目录（停写 → 移动 → 重启）
- 全量导出：zip（db 快照 + files + config；默认不含密钥，可选勾选含）
- 从导出包导入：换机恢复（新机首启选空目录 → 导入校验落位，§6.4）
- 建课程按角色预选默认场景的联动（P0-05 已按档案缺失做中性默认，本 plan 使其真正生效）

**不做**：
- 登录 / 账号 / 密码（整体作废，#55）、应用锁（P3+ 评估）、Windows 凭据管理器（P3+ 评估，#11）
- 快照备份 WebDAV/S3（P2，单向推送）

## 核心业务流程

设置 → 档案：改昵称 / 头像 / 角色 / 自我介绍 → 本地保存生效；供应商卡：增改端点 → 连接测试 → 生效；数据目录：打开 / 更改（移动+重启）；全量导出 zip → 新机导入恢复

## 关键业务规则

- **角色改变语气与默认值，不改变能力集**（#52）：永不进入课程范围 AI 管线与 Learning Evidence
- 角色改动对自由聊天"新会话生效不追溯"（与 12 验收联动）
- LLM 可自选任意 OpenAI 兼容端点，DashScope 为默认预设（#55）；Embedding V1 固定
- 导出默认不含 providers.json；勾选含密钥时明示明文风险（#11）
- 数据目录是唯一事实源，同一时刻不可双写（更改目录必须经停写-移动-重启）
