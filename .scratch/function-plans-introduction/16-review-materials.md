# 16 - 复习资料

> Wave: B ｜ PRD: §4.4.2 复习资料行 ｜ 决策引用: 无新增（v1.1 定稿形态）

## 功能描述 / 目标

考前速记材料的一键生成：基于已确认总结与知识点产出三段式复习资料，含 Markdown 大纲树形渲染，接入 10 的导出通道。

## 功能范围

**做**：
- 按需生成：考前速记（浓缩要点）+ Top 重点清单 + Markdown 大纲思维导图（按标题层级）
- 大纲树形渲染：可折叠树组件（不做图形化导图导出）
- 复习资料 Markdown 渲染统一组件（含代码高亮，程序员场景默认含代码块）
- 接入 10：复习资料一键导出 `.md`
- HITL：生成结果可调整反馈重新生成（不限次）

**不做**：
- 图形化思维导图导出、遗忘曲线驱动的复习排期（P4 遗忘雷达）、复习队列（P4）

## 核心业务流程

总结与知识点已确认 → 复习 tab → 生成 → 三段式呈现（速记 / 重点清单 / 大纲树）→ 调整或确认 → 可导出 `.md`

## 关键业务规则

- 生成上下文 = 已确认总结 + 已确认知识点（不是原始转写全文）
- AI 上下文含课程 learning_context / 深度字段（同总结规则）
- 资料版本随生成留痕（model / prompt_version）
- 输出全文不进日志

- [ ] 大纲树可折叠展开，层级正确
- [ ] 含代码块时高亮渲染正确（亮 / 暗双主题）
- [ ] 导出 `.md` 与界面内容一致
